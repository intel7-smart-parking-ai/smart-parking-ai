🖥️ 내 PC에서 로컬 서버(FastAPI + SQLite 또는 내장 HTTP 서버)로 실행하는 3가지 방법
방법 1. FastAPI + SQLite 서버 (권장)

제공된 smart_parking_local_server.zip 압축 해제 후 터미널에서 실행:

pip install -r requirements.txt
python server.py
→ http://127.0.0.1:8000 및 Swagger /docs 자동 활성화
방법 2. 설치 없는 파이썬 내장 API+DB 서버

fastapi 미설치 환경에서도 표준 sqlite3 + http.server로 즉시 구동:

python server.py --builtin
→ Windows에서는 run_server.bat 더블클릭만으로 즉시 실행
방법 3. 단일 HTML 정적 웹 서버 구동

ai_led.html 파일이 있는 폴더에서 파이썬 기본 웹 서버 한 줄 실행:

python -m http.server 8000
→ http://localhost:8000/ai_led.html 접속
