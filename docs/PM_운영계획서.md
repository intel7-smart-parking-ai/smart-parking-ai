## 1. PM 및 조직 체계

PM 확정: 김한별. PM은 1팀 차량 탐지 개발을 겸임하며, 개별 모델 개발 책임을 다른 팀원에게 전가하지 않는다.


| 구분 | 인원 | 담당 |
| --- | --- | --- |
| PM | 김한별 | 일정·범위·Jira·위험·통합·보고 총괄 |
| 1팀 | 김한별 · 박해준 | 차량 탐지 및 주차 공간 인식 |
| 2팀 | 우지원 · 김채린 | 차량 번호 스티커(번호판) 인식 |
| 3팀 | 윤명수 · 서정범 | LED 모의 화재 상황 인식 |

## 2. PM 책임 및 권한

- 범위: 필수 / 확장 기능 구분 및 변경 요청 이력 관리
- 업무: 에픽·Task·담당·기한·완료 기준 확정, 매일 진행상황 확인
- 품질: AI 추론 결과, DB, 앱/관리자 화면의 연동 테스트 총괄
- 의사결정: 장애 발생 시 우선순위 재조정, 9일차 기능 추가 동결
- 대외 보고: 착수보고·중간 진행 공유·최종 시연 준비

## 6. Jira 운영 규칙

- Epic은 기능 단위, Task는 독립 검증 가능한 결과 단위로 생성
- 컬럼: 할 일 → 진행 중 → 검토/테스트 → 완료(가능할 경우)
- 완료 기준: 실행 증거(스크린샷/영상), 테스트 결과, GitHub PR 또는 커밋 링크
- 매일 10~15분 진행 점검: 어제 완료 / 오늘 계획 / 차단 이슈
- 모든 AI 코딩 결과는 직접 실행·검토하고 비밀키는 .env로 관리
## 7. 주요 위험과 대응


| 위험 | 대응 |
