| 항목 | 내용 |

## 2. 추진 배경 및 목적

주차 공간 점유 여부, 차량 위치, 이상 상황, 요금·매출 정보를 개별적으로 확인하는 불편을 줄이는 통합 관리 흐름을 소형 모형으로 검증한다. 실제 주차장 규모 운영을 구현하는 것이 아니라 AI 인식과 관제·운영 시스템 간 연동 가능성을 시연하는 것이 목적이다.

## 3. 개발 범위 및 기능


| 구분 | 핵심 기능 | 기술/구현 |
| --- | --- | --- |
| 비전 AI | 차량 탐지 및 주차칸 점유 판별 | 객체 탐지 + 다각형 ROI + 안정화 |
| 차량 식별 | 지붕 숫자 스티커 01~24 인식 | OCR / 필요시 대체 마커 |
| 안전 이벤트 | 빨간 LED 모의 화재 인식·경고 | 영상 탐지·관리자 알림 |
| 통합 플랫폼 | A·B 실물 + C 가상 정보 수집 | FastAPI + DB |
| 사용자 서비스 | 빈자리·차량 위치·요금·챗봇 | 모바일 웹/PWA |
| 관리자 서비스 | 카메라·입출차·요금·모의 결제·월 매출 | 웹 대시보드 |
| 선택 개발 | 음성인식, D 가상 주차장, 고급 통계 | 일정 여유 시 |

## 4. 설치·인식 방식

- 카메라 설치 위치 미정: 중앙 상단에서 전체를 내려다보는 방식 또는 모서리 상단에서 전체를 대각선으로 촬영하는 방식 중 비교 테스트 후 선택
- 주차칸은 카메라 영상에서 사각형 다각형 좌표(ROI)를 최초 등록하고 고정 카메라 기준으로 관리
- 자동차 탐지 결과를 ROI와 매칭하고 지속 시간·겹침을 고려해 점유 확정
- 차량 번호 인식 불확실 시 미확인 상태를 유지하고 근거 없는 번호를 생성하지 않음
- 주차칸 간 이동을 입출차로 간주하지 않으며 입출차 이벤트는 별도 규칙으로 기록
## 5. 6인 팀 구성 및 공동 AI 개발


| 개발팀 | 팀원 | 전 과정 공동 수행 |
| --- | --- | --- |
| 1팀 | 김한별 · 박해준 | 차량 탐지 및 주차 공간 인식 |
| 2팀 | 우지원 · 김채린 | 차량 번호 스티커(번호판) 인식 |
| 3팀 | 윤명수 · 서정범 | LED 모의 화재 상황 인식 |

각 팀은 데이터 수집 → 라벨링 → 학습 → 테스트 → 성능 개선 → 시스템 연동을 공동 수행한다. PM: 김한별(확정). 운영·웹·DB·LLM은 AI 팀 작업과 별도로 역할 분담한다.

## 6. 시스템 데이터 흐름

A/B 카메라 → 차량 탐지·OCR·LED 인식 → 주차칸 상태 통합 → FastAPI/DB ← C(/D) 가상 이벤트 → 사용자 모바일 웹·관리자 관제·LLM 조회

## 8. 구매 및 예산 계획

구매 요청 8종: 미니카 12종 세트(2세트), 10T 보드롱(2장), 양면테이프, 3cm 무선 LED 5p·리모컨, 숫자 스티커, 예비 SMD LED, CR2032 홀더, CR2032 배터리. 카메라 2대·브레드보드·저항은 보유. 이미 확인된 최초 5개 품목 합계 52,600원이며 나머지 3개 가격·수량 및 도면 출력 비용은 최종 확인 필요.

## 9. 위험 요소 및 대응 전략


| 이슈 | 대응 |
| --- | --- |
| 카메라 위치별 가림·원근 | 중앙/모서리 상단 비교, 주차칸 ROI·카메라 각도 실측 검증 |
| 숫자 스티커 OCR 오류 | 실제 화면 픽셀 크기 확인, 전처리 후 필요 시 마커 대체 |
| 모델 학습 및 통합 지연 | 일차별 통합, 모의 JSON으로 웹·서버 병렬 개발 |
| 입출차 오판으로 요금 오류 | 주차칸 이동과 출차 구분, 상태 유지 및 수동 확인 |
| LED 반사·오탐지 | 조명 조건별 데이터 확보, 경고 수동 시연 대안 |

## 10. 완료 기준 및 시연 시나리오

- A/B 실물 주차장의 차량 탐지 및 주차면 점유 상태를 화면에서 확인
- 번호 인식 결과를 주차장/주차칸과 연계하고 미인식 예외를 확인
- LED 점등 시 모의 화재 경고를 발생시키고 관제 화면에서 확인
- 사용자 모바일 웹에서 빈자리 조회·차량 검색·요금 확인·모의 결제
- 관리자 화면에서 A/B/C 운영현황, 결제 내역, 월 매출 통계 조회
- LLM 챗봇이 실제 조회 API 결과에 근거해 주차장 질문에 응답
## 11. 기대 성과

AI 비전·LLM·백엔드·프론트엔드 기술을 연계해 소형 관제 시스템을 구현하고, 다중 주차장 통합 관리와 운영정보 시각화의 구현 가능성을 실증한다. 실제 상용 성능이나 실화재 감지 성능을 주장하지 않는다.
