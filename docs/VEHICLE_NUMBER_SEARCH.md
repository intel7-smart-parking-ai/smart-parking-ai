# 실물/가상 주차장 차량 검색

2026-11-03 사용자 지시에 따라 검색 방식을 분리했습니다.

| 구분 | 검색 | 예시 | 결과 |
| --- | --- | --- | --- |
| 1번·2번 실물 | 미니카 스티커 01~24 | 07, 12 | 스티커 번호·주차장·도면 칸 번호·서버 요금 |
| 3번·4번 가상 | 차량번호 뒤 4자리 | 9012, 3456 | 56다9012, 78라3456·주차장·도면 칸 번호·서버 요금 |

주차장을 선택하면 검색 방식이 자동 전환됩니다. 내 차 찾기·빠른 찾기·이용요금에서 탭을 직접 바꿀 수도 있습니다. 실물 스티커 한 자리 입력 7은 07로 정규화합니다. 가상 0022처럼 앞자리 0이 있는 번호는 보존합니다.

독립 목업 API:
- GET /demo-api/v1/sticker-search?car_id=07: 실물 A/B만 조회.
- GET /demo-api/v1/vehicle-search?vehicle_number=9012: 가상 C/D만 조회.

각 응답은 lookup_type, session_id, space_id(기존 내부 ID), space_label(도면 표시 번호), fee를 포함합니다. 가상 응답은 vehicle_number와 plate_number를 포함합니다. 실물 응답에는 가상 번호판을 붙이지 않습니다. 다른 범위의 차량이나 없는 차량은 404, 중복 활성 세션은 409, 잘못된 입력은 422입니다.

번호판·주차 상태는 합성 목업 데이터입니다. 실제 OCR 입력과 공식 요금 모듈은 연결 전이며 요금은 기존 server_fixture를 사용합니다. UI는 금액을 재계산하지 않습니다. 내부 car_id와 세션·결제 이력은 보존합니다. 팀 공통 API 계약은 변경하지 않습니다.

검증: 프론트엔드 테스트 16개 통과, PDF 면수/배치 메타데이터 및 실물/가상 검색 범위 HTTP 검사 통과, 브라우저에서 07 → 1번 B-06 / 5,000원, 9012 → 3번 A-04 / 2,600원 확인.
