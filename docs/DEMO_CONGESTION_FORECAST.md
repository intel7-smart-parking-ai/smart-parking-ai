# 시뮬레이션 혼잡 예측 — 로컬 구현

2026-11-08. 김해공항(C)·신세계(D) 가상 주차장만 지원합니다. 공개 사이트에는 배포하지 않았습니다.

## 처리 흐름

질문 → forecast_query.py의 LLM이 방문 날짜·시각·주차장 추출 → 코드가 명시 주차장·시각·지원 범위 검증 → GET /api/v1/congestion/forecast → congestion.py가 계산 → 짧은 답변 + ‘시간대별 혼잡도 보기’ 버튼.

LLM은 빈자리나 혼잡도를 생성하지 않습니다. 실패하면 보수적인 날짜·시각 규칙으로 처리합니다. ‘2시’는 오전·오후를 되묻고, 위치가 없으면 최근 주차장 맥락 또는 추가 질문을 사용합니다. 지원 범위는 현재 이후 7일 이내입니다. 과거 시각은 내일로 임의 이동하지 않습니다. 경보·관리자 권한·결제 확인 절차는 유지합니다.

## 시연 기록

backend/app/simulation/congestion.py에서 입출차 수와 점유 변화를 시간별로 계산합니다. 김해공항은 오전·저녁, 신세계는 오후·주말 수요가 높은 시나리오입니다. 2026-08-01부터 서버 날짜 전날까지 재현 가능한 난수로 생성하며 demo_congestion_history 테이블에 버전별로 저장합니다. 생성한 과거 시나리오이며 실제 관측 기록이 아닙니다. 서버 시작 및 날짜 변경 시 누락 기록을 보완합니다.

현재 지도의 점유 상태·실제 차량 세션·vacancy_history는 수정하지 않습니다. 실시간 차량 시뮬레이터와 독립된 예측 실험용 기록입니다. 따라서 현재 빈자리와 미래 예상 빈자리는 다를 수 있습니다. 이 데이터로 실제 공항·백화점 혼잡을 예측할 수 있다고 주장하지 않습니다.

## 계산 및 검증

같은 요일·시간대의 과거 평균 빈자리를 사용합니다. 점유율 60% 미만은 여유, 60~85% 미만은 보통, 85% 이상은 혼잡입니다. 시간 단위 모델이므로 14시 30분도 14시대 추정값을 사용합니다.

최소 28일 학습 + 이후 14일 평가, 공통 시간대 90% 이상 기준입니다. 하루씩 예측 시점을 이동하며 그 시점 이전 기록만 사용합니다. 전날·지난주 같은 시각과 비교하고 MAE/RMSE를 계산합니다. 예측 API에는 평가 구간의 MAE와 평가 표본 수가 포함됩니다. MAE는 평균 오차이며 신뢰구간 또는 정확도 보장이 아닙니다.

2026-11-08 시연 기록 평가: 김해공항 MAE 약 2.6자리, 신세계 약 2.0자리, 각각 336개 시간대. 날짜가 지나 기록이 추가되면 값은 바뀔 수 있습니다. 실서비스 적합성 검증은 별도로 필요합니다.

## API와 화면

예측 완료 후에도 주차장·날짜·시각을 세션의 공통 조회 맥락 유효 기간 동안 보관합니다. ‘내일 오후 2시 김해공항’ 다음 ‘토요일3시는?’은 다가오는 토요일 오후 3시 김해공항으로 조회합니다. 날짜만 바꾸면 시각을, 주차장만 바꾸면 날짜·시각을 유지합니다. 명시적인 오전·오후가 이전 조건보다 우선합니다. 다른 업무 조회로 전환하거나 맥락이 만료되면 오래된 예측을 재사용하지 않습니다. Langfuse forecast 프롬프트 v2에 같은 규칙을 반영했습니다.

GET /api/v1/congestion/forecast?lot_id=C&at=2026-11-09T14%3A00%3A00%2B09%3A00

시간대가 있는 ISO 시각이 필수입니다. 실운영 모드·A/B 주차장·과거·7일 초과 시각은 예측을 반환하지 않습니다. 응답은 source=simulation, is_mock=true, label=시뮬레이션 기반 예측을 포함합니다.

답변 예: ‘11월 9일 오후 2시 김해공항 주차장은 여유로울 것으로 예상돼요. 예상 빈자리: 약 41자리. ※ 시뮬레이션 기반 예측’.

버튼을 누르면 해당 날짜의 앞으로 남은 시간대별 빈자리·혼잡도·시연 검증 평균 오차가 펼쳐집니다. 자동으로 펼치지 않습니다.

Langfuse production 프롬프트 이름: parkon-report-forecast. CallbackHandler 실행 이름: forecast-query-interpretation. 모델 호출에서 시각 추출만 추적하며 예측 숫자는 서버 코드에서 계산합니다.
