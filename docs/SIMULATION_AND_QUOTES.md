# 가상 주차장 입출차 시뮬레이션 / 견적 만료 처리

- 관리자에서 3번(C) 또는 4번(D)을 선택하면 전용 제어 패널이 나옵니다. `/admin/?lot=C`, `/admin/?lot=D`로 바로 열 수 있습니다.
- 수동 입차: 차량 뒤 4자리와 빈 칸을 선택하거나 비워서 자동 선택. 기존 주차 차량/실물 차량을 중복 입차시키지 않습니다.
- 수동 출차: 주차 차량을 골라 출차. 모의 출차는 미결제도 허용하지만 결제를 자동 생성하지 않습니다.
- 자동 실행: 3~30초 간격을 선택. 서버 작업자가 입차/출차를 번갈아 발생시키고 차량과 칸은 임의 선택합니다. 빈자리·차량 위치·활성 세션·이력이 DB에서 함께 갱신됩니다.
- 일시정지: 이후 자동 입출차를 중단합니다. 실행 설정은 DB에 저장되므로 브라우저를 닫아도 계속되며 서버 재시작 후에도 설정에 따라 재개됩니다.
- 1·2번 실물 주차장에는 시뮬레이션 명령을 적용할 수 없습니다. 관리자 API 인증 및 CSRF 검사를 거칩니다. 공개 사용자에게 조작 API를 열지 않습니다.
- 종료된 모의 세션으로 결제를 만들 수 없습니다. 재입차는 새 세션 ID를 사용합니다. 기존 세션·결제 이력은 삭제하지 않습니다.
- PM D-02: 세션 상태는 `active`/`closed`입니다. 기존 `parked`/`exited` 행은 세션 ID와 결제 참조를 보존해 이관합니다.
- 요금은 여전히 데모 고정 샘플 견적입니다. 실시간 요금 알고리즘/실제 결제/카메라 인식을 구현한 것은 아닙니다. 가상 세션의 이용 시간과 계산 시각은 실제 모의 입출차 시각을 표시합니다.

## 견적 결제 호환
- 결제 직전 요금 API에 `quote_id`가 있으면 요청에 포함합니다. 없으면 해당 키 자체를 보내지 않습니다.
- 데모 서버는 선택적 quote_id를 받아 세션 견적과 일치하는지 검사합니다. quote_id를 아직 제공하지 않는 팀 API에는 기존 3개 필드만 전송합니다.
- 요금 화면은 조회 시점부터 2분 뒤 미결제 견적을 초기화합니다. 탭 복귀 시에도 현재 시각으로 검사합니다. 완료된 영수증은 지우지 않습니다.
- QUOTE_EXPIRED/QUOTE_MISMATCH/QUOTE_CHANGED는 오래된 결제 시도를 제거하고 요금 재조회를 요구합니다. 자동으로 새 견적에 결제하지 않습니다.
- 최신 요금이 화면에 표시된 금액과 다르면 결제하지 않고 재조회를 안내합니다. 네트워크 오류의 멱등키 보존 규칙은 유지합니다.

- A 개발원주차장, B 부산역주차장, C 북항주차장, D 신세계백화점주차장.

시작 시 DB 요금 정책을 갱신하며, 고정 샘플 견적도 새 요금에 맞췄습니다. 실시간 이용 시간별 요금 계산은 여전히 공식 billing 연결 범위입니다. 기존 결제 금액은 변경하지 않습니다.
- 지도 아래로 이동하는 주차 현황·차량 찾기 카드는 두 열을 균등하게 채우고, 520px 이하에서는 한 열로 표시합니다. 관리자 경보 카드는 별도 전체 폭을 사용합니다.
- 로컬 IP·인증정보와 실행 중 터널 주소는 소스에 포함하지 않습니다. 외부 공개는 compose의 external 프로필로 실행하며, 임시 터널 재시작 시 주소가 바뀝니다.

## PM 검토 후 계약 정렬
- 간편결제 표시는 피넛페이(모의), 보라색 브랜드 배지로 표시합니다. API 수단은 MOCK_EASY_PAY를 유지합니다.
- 공간 식별은 space_id 하나를 사용합니다. zone은 도면 내 그룹 메타데이터이며 별도 공간 식별자가 아닙니다. 기존 DB의 미사용 표시 열은 데이터 보존을 위해 삭제하지 않고 API에서 제외합니다.
- 프론트 PR은 main을 기준으로 frontend/ 디렉터리만 분리합니다. 데모 API 변경은 기존 통합 브랜치에서 별도로 검토합니다.
