총 50면입니다. 초록색은 전기차, 파란색은 장애인 구역입니다. 출입구와 진행 화살표는 첨부 도면을 따릅니다. 화면 폭에 맞춰 전체 도면을 표시하고 주차칸 확대 시 좌우로 이동할 수 있습니다.

출처: 사용자 제공 01_기본형_12칸_A4_4장_25pt.pdf, 02_사선형_16칸_A4_4장_25pt.pdf, 03_일방순환형_12칸_A4_4장_25pt.pdf, 04_L자복합형_10칸_A4_4장_25pt.pdf. 각 4페이지의 2x2 분할을 렌더링해 확인했습니다. 원본 PDF는 저장소에 복사하지 않았습니다.

도면 내부 A/B 구역과 시스템 lot_id는 다릅니다. parking_spaces.bay_label은 도면 번호이고 기존 space_id는 세션·결제·경보 참조용으로 유지합니다. 예를 들어 1번 내부 A-12는 도면 B-06입니다. 2번은 12→16면, 3번은 10→12면으로 확장하고 기존 차량·결제·취소 기록은 삭제하지 않았습니다. 신규 칸은 비어 있는 합성 상태로 추가합니다.

레이아웃 기준 데이터는 dev/parkon-api/app/layouts.py에 있고 SVG 도형은 frontend/src/ParkingLayoutMap.jsx에서 표시합니다. 실제 카메라 ROI 좌표나 공식 서버의 배치를 변경하지 않습니다. 팀 API 조회 모드는 기존 팀 목업 계약을 유지합니다.

검증: scripts/verify_layouts.py로 50면, 지역별 표시 번호, 전용 구역 수, 검색 범위를 확인했습니다. scripts/verify_team_routing.py로 팀 API와 독립 목업의 분리를 확인했습니다. 기존 0022 모의 결제 영수증은 유지됩니다.

최종 주차장.png 기준으로 구획선·노란 휠 스토퍼·차로 중앙선도 반영했습니다. 사용자 화면은 항상 최종 4개 주차장을 사용하며 과거 ?source=team 링크도 같은 화면을 표시합니다. 팀 API 자체 /api/v1 경로와 서버 코드는 유지하며 화면의 이전 데이터 소스 선택 버튼은 제거했습니다.
