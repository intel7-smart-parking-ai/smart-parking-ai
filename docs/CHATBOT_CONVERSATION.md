# 공통 대화 의도·맥락 처리

2026-11-08 로컬 적용.

## 흐름

안전·권한 보호를 유지하면서 인사/감사/짧은 불만/재설명/모호한 요청을 규칙으로 처리합니다. 명확한 주차 업무는 기존 기능을 실행합니다. ‘그럼 공항은?’처럼 생략된 후속 질문은 직전 조회의 전기차·장애인·구역 조건을 유지하고 주차장만 교체합니다. 한 세션의 유효 기간 내에서만 맥락을 사용하며, 새 대화 시작 시 지웁니다.

예:
- ㅎㅇ → 인사와 지원 기능 안내
- 고마워 → 감사 응답
- 왜 이래? → 문제가 된 기능을 구체적으로 질문
- 뭐지? / 다시 설명해줘 → 직전 설명 재안내. 실시간 수치는 직전 안내임을 표시
- 도와줘 → 차량 위치/빈자리 등 구체적인 선택 질문
- 부산역 전기차 빈자리 → 그럼 공항은? → 김해공항의 전기차 빈자리 재조회

## 미해석 표현

REPORT_OPENROUTER_KEY가 설정돼 있으면 미해석 표현만 추가 LLM 분류를 사용합니다. 새 Langfuse 텍스트 프롬프트는 parkon-report-conversation입니다. 분류는 intent와 허용된 조회 task만 반환하며 자연어 사실 답변을 생성하지 않습니다. 3초 API 시간 제한과 JSON 검증을 적용합니다. 키 미설정·시간 초과·잘못된 응답은 구체적인 재질문으로 처리합니다.

LLM이 선택할 수 있는 업무는 빈자리/차량 위치/차량 요금/요금표/정책/충전 현황뿐입니다. 결제·취소·예약 확정·관리자 호출 실행이나 관리자 데이터 권한을 생성하지 않습니다. 인사·감사·알겠어는 진행 중인 결제 확인을 승인하지 않습니다.

REPORT_LANGFUSE=1이면 conversation-interpretation 콜백 trace에 분류·프롬프트 버전·소요 시간을 남깁니다. 콜백 입력 상태에는 질문 원문이나 조회 결과를 넣지 않고 모델 호출의 지역 변수로만 처리합니다. 업무 결과는 기존 API/등록 안내/경로 계산을 통해 확인합니다.

## 소스·검증

- parking-chatbot/chatbot/conversation.py: 공통 반응·후속 질문·유효 기간
- state.py: 세션별 대화 슬롯
- engine.py: 공통 대화 → 기존 업무 → 미해석 시 LLM 순서
- report_lab/conversation_llm.py: 제한된 의미 분류
- report_lab/prompts.py: 프롬프트 기본값과 Langfuse 관리
- tests/test_conversation.py: 사회적 대화, 맥락, 확인 보존, 경보, 모델 실패 검사

실제 로컬 HTTP 확인에서 ‘ㅎㅇ→뭐지?→고마워→왜 이래?→도와줘’는 모델 없이 처리됐고, ‘차 놓을 데 찾아볼래’는 실제 LLM 해석 후 빈자리 조회로 연결됐습니다.
