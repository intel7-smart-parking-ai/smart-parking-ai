## 시연 직전 체크 (5분)
0. **판 초기화**: 두 판에서 차를 **전부 빼고 10초** → 모든 세션 정상 출차 → 시연 배치대로 **한 대씩** 놓기 (차를 많이 옮길수록 서버 세션이 꼬여 "확인 필요"가 누적되므로, 리허설 전·시연 직전에 한 번씩)
1. 카메라 PC: 시간 동기화 → `start_demo_send.ps1` → 시간차 ±0.2초 → 토큰 → 자동 승인·전송(5초)
2. 시연 사이트: A·B·C·D 모두 observing, 확인 필요 0, **active 경보 0**
3. LED 차는 LED 끈 채 놓고 번호 확인 → 필요할 때 켜기
4. 챗봇 리허설 문장 1개로 응답 확인(AI 켜짐)
5. 관리자 화면 열어 두기(경보 해제용), 사이렌 소리 확인
