## 갱신 방법

1. 작업이 **main에 병합**되면 해당 줄을 `- [x]`로 바꾸고 PR 번호를 적는다.
2. 브랜치·PR 진행 중이면 ◐와 브랜치명을 적는다.
3. 맨 위 "최종 갱신" 시각과 요약 표 숫자를 함께 고친다.
4. 이 문서 변경은 `chore/progress-*` 브랜치 PR로 올린다 (main 직접 수정 금지).
