# Coordinator 및 모델 연결 상태

구현은 단일 모델을 요청당 최대 두 번 호출한다. 첫 호출은 의도와 인자를 반환하고,
두 번째 호출은 검증된 사실 ID를 정렬한다. 두 번째 호출 실패 시 기본 사실 문장을 사용한다.
모의 모델 테스트는 처리 흐름을 검증하며 실제 한국어 의미 해석 성능을 입증하지 않는다.

- OpenRouter 고정 endpoint, 강제 function tool 출력, 구조 검증.
- `OPENROUTER_API_KEY`와 `OPENROUTER_MODEL` 필수.
- `LLM_MODEL`은 대체 설정명. 두 모델명이 다르면 중단.
- 명시한 dotenv 파일만 읽고 프로세스 환경 변수가 우선.
- 기본 모델을 임의로 선택하지 않음. 특정 모델의 가용성·가격은 별도 확인 필요.
- 공급자 오류 원문/키를 사용자 응답에 출력하지 않음.

복구 중 유료 API 호출은 수행하지 않았다. 현재 확인된 클라우드 secrets 목록은 비어 있다.
사용자가 과거 설정을 입력하지 않았다는 뜻이 아니라 현재 런타임에서 연결되지 않았다는 뜻이다.
Langfuse trace와 프롬프트 버전 관리, 실제 모델 질의 평가, 전체 턴 시간제한은 후속 작업이다.
