# 근거 없는 장소 확인 질문 보완

직전 실제 6문항은 사전 의미 기준 6/6이었으나 G01의 확인 질문이 신새계를 신세계로 바꿔 말했고 G02도 신세계를 제안했다.

이번 변경은 프롬프트에서 후보 밖 장소를 확인 질문에 제안하지 않도록 명시하고, 서비스 표시 경계에서도 확인한다. clarify 질문에 요청 후보 밖 카탈로그 이름·별칭·주차장 ID 명칭이 나오면 다음 중립 문구로 표시한다.

> 어느 주차장을 말씀하시는지 이름을 확인해 주세요.

모델의 Decision, lot_id, 후보 목록은 수정하지 않는다. 자동 장소 교정이 아닌 사용자 표시 문구 보호이며 도구 호출이나 문맥 갱신을 하지 않는다. 실제 모델이 중립 문구를 생성했다고 집계해서는 안 된다.

정상 후보의 시설 확인 질문, 장소 이름 없는 질문, ASCII 숫자 재입력·차량번호 확인은 유지한다. 부정된 장소를 다시 제안하는 경우와 띄어쓰기·D 주차장 표현도 시험했다. 카탈로그 밖 모든 실존 장소/미등록 재표현의 탐지를 보장하는 기능은 아니다.

- 기존 실제 G01/G02 문구를 모의 모델에 넣어 화면 응답, 문맥 미변경, 재전송 시 모델 미재호출을 확인했다.
- Python 3.11.9, 고정 의존성, fixture. 유료 모델 호출 0회, Langfuse 외부 전송 없음.
- 프롬프트가 변경됐으므로 직전 실제 6/6을 이번 버전의 실제 성능으로 재사용하지 않는다.
- 다음 34문항 유료 평가는 아직 실행하지 않았다. 승인 후 Coordinator 단독으로 평가하고 모델 원문 의미와 서버 표시 경계를 따로 기록해야 한다.
