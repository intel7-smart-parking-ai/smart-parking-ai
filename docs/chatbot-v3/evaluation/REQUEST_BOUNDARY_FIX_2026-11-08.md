# 3회차 신규 실패의 오프라인 보완

실제 기준 점수는 RUN_2026-11-08_COORDINATOR_3.md의 32/34다.
이번 작업에서 유료 모델/주차 API/Langfuse를 추가 호출하지 않았다.

## 장소 확인

카탈로그 language_profile.ambiguous_examples를 모델 참고 자료뿐 아니라 실행 제약으로 사용한다.
차량/요금 외 의도에서 선택한 주차장의 모호 표현이 질문에 있으면 API/설정집 실행 전에 확인 안내로 끝낸다.
공백과 대소문자를 정리해 비교하되 fuzzy match나 오타 자동 교정을 하지 않는다.
이에 따라 Q16의 facilities/D + 신세게 주차장 응답은 실행하지 않는다.
모호 표현이 부정/정정 안에 있어도 보수적으로 다시 확인할 수 있다는 제한이 있다.
새 장소나 사용자 표현 전체를 해결하는 의미 판별기가 아니다.

## 전체 범위 조회

availability의 lot_id=null은 더 이상 장소 누락을 자동으로 전체 주차장 조회로 확대하지 않는다.
사용자가 전체/모든/각 주차장, 주차장 전체/모두, 주차장별처럼 전체 범위를 명시해야 허용한다.
기존 도구의 전체 현황 기능은 유지하지만 지원 표현 밖의 요청은 확인 안내로 끝날 수 있다.
이 검증은 조회 범위 확인이며 일반 의도 파서를 다시 만드는 방식은 아니다.
Q33의 허위 빈자리 지시에는 전체 범위가 없어 관측된 availability/null 응답을 실행하지 않는다.

전체 범위를 함께 명시하거나 특정 lot_id로 잘못 분류된 악성 요구를 모두 차단하지는 않는다.
일반적 프롬프트 주입 해결이나 안전 보장을 주장하지 않는다. 답변 사실은 여전히 서버 근거로 생성한다.

## 모델 지시

임의 값/시스템 지시 변경 요구는 조회로 바꾸지 않도록 우선 지시를 추가했다.
조회 목적 없는 장소 이름만의 입력과 ambiguous_examples의 오타/미확정 표현은 clarify로 확인하도록 했다.
이 지시의 실제 모델 효과는 미검증이며 기존 기대값/평가 점수를 변경하지 않았다.
