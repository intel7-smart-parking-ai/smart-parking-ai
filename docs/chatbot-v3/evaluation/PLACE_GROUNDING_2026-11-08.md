# 장소 선택 근거 검증 · 2026-11-08

## 문제와 보완

직전 소량 시험의 새 오타 '신새계 쪽 주차장 안내해줘'는 guidance/D로 단정됐고 기존 경계를 통과했다.
등록된 모호 표현 목록만 늘리지 않고, 선택된 lot_id에 대해 place_grounding.place_evidence로 근거를 확인한다.
검증기는 장소나 의도를 선택하지 않고 모델이 선택한 장소의 근거가 없으면 실행을 중단한다.

- 카탈로그 name/name_variants의 등록 표현: 명시 이름 근거.
- types/related_places/purposes/semantic_examples의 등록 표현: 관련 시설/목적 근거.
  기존 확정 장소와 다르면 이 약한 근거만으로 자동 이동하지 않는다.
- confirmed_context의 같은 lot_id + 거기/그곳/해당 주차장/이 주차장: 문맥 근거.
  다른 등록 장소 이름이 현재 질문에 명시돼 있으면 문맥으로 덮어쓰지 않는다.
- 공백/대소문자만 정리한다. 편집거리/철자 교정/오타 정규화는 없다.
- 한 글자 별칭은 일반 단어 안에서 일치하지 않도록 단어 경계를 요구한다.
- 차량/요금은 원래 서버가 위치를 결정하므로 이 장소 선택 검증의 대상이 아니다.
- 전체 주차장 조회는 기존 명시 범위 검증을 사용한다.

근거 없음은 기존 확인 안내로 끝나며 조회/문맥 변경/동일 요청 재실행을 하지 않는다.
새 오타를 D의 별칭으로 추가하거나 평가 기대값을 바꾸지 않았다. 모델 공급자 출력 형식은 변경하지 않았다.

## 보존한 정상 경로

KTX/기차주차장/역 주차장/국제선/영화관/교육 참석/등록된 영화 목적 문장,
공백이 다른 신세계 이름, 부산역에서 공항으로 명시 변경, 확인된 거기/그곳 참조를 시험했다.
신새계/신세개, 근거 없는 이전 문맥 재사용, 다른 주차장과 충돌한 영화관,
일반 단어 안의 비/시/디가 장소 별칭으로 오인되지 않는지 확인했다.
