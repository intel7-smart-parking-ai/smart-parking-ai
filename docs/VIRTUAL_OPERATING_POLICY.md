## 가상 충전 상태 API

별도 하드웨어나 외부 서비스 연결이 아닌, 기존 서버의 가상 충전 시뮬레이션입니다. C/D의 전기차 칸에만 적용합니다.

- `GET /api/v1/parking-lots/{lot}/spaces`의 각 전기차 칸에 `charging` 제공.
- `source=simulation`, `is_mock=true`, `status`, `connected`, `power_kw`, `observed_at`.
- 빈칸: available. 전기차 입차 후 15초 연결 대기, 120초 7kW 충전, 이후 완료·0kW.
- 비전기차: not_connected. 관측 불확실·세션 없음: unknown. 출차 후 available.
- 실제 A/B 주차장: not_connected 출처·unknown, 출력 미제공.
- 충전 상태는 관측 세션과 시연 시간으로 계산하며, 요금·결제·주차 세션을 변경하지 않습니다.
- 시작화면의 충전 현황 및 챗봇 ‘공항 충전 상태’에서 확인합니다. 화면은 기존 API 주기로 새로 조회합니다.

근거·변경 위치: lots.json의 guide, MallParkingMap.jsx, ParkingLayoutMap.jsx, simulation/charging.py, runtime.py의 enrich, ChargingStatus.jsx.

실제 장비 연동 시에는 공급사 API·인증·충전기 ID와 주차칸 매핑이 필요하며, 이 시뮬레이션 출처를 실제 장비로 표시해서는 안 됩니다.
