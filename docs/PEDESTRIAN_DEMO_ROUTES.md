# 도면 기준 시연 보행 경로

## 개별 칸 안내 변경

현재 답변은 `추천 주차칸: B-07`처럼 개별 칸 번호만 표시합니다. 같은 최단 거리의 칸은 모두 나열합니다. 기본 추천은 API에서 empty로 확인된 일반 칸이며, 전기차·장애인 조건을 명시하면 해당 유형만 비교합니다. A1/B7 같은 입력은 A-01/B-07로 정규화합니다. 특정 칸에서 출발하는 질문은 그 칸의 점유 여부와 무관하게 경로만 안내합니다.

칸 좌표는 실제 화면의 행·열 배치와 일치시키고 각 칸에서 인접 통로로 연결합니다. 주차된 다른 칸을 가로지르는 연결은 만들지 않습니다. 아래 구역별 결과는 기존 큰 구역 비교 설명이며, 현재 답변의 추천 단위는 그 안의 개별 칸입니다. 실제 보행 거리·시간 미측정이라는 한계는 동일합니다.

차량용 입구·출구와 건물 연결 출입구를 구분했습니다. 차량 진입·출차 경로와 비상 대피 경로를 계산하는 기능은 아닙니다.

## 계산 범위

공항은 P1/P2/P3의 북쪽 구역 연결지점, 청사 앞 연결통로, 국내선·국제선·국제화물청사 연결지점을 그래프로 정의합니다. 화장실은 도면의 청사 내부 아이콘 위치에 연결합니다.

신세계는 구역 중앙 통로 연결지점에서 주차칸을 가로지르지 않고 구역 옆 통로·건물 앞 통로로 연결합니다. 아래쪽 몰·백화점 연결 출입구, 위쪽 엘리베이터·화장실·영화관 방향 표시를 목적지로 사용합니다. 중앙 횡단 연결은 시연용 가정입니다.

이미지에는 실제 보행 전용 통로·축척·건물 문 위치의 실측 정보가 없습니다. 따라서 그래프의 연결은 시연 설정이며, 실측 시설 경로나 공식 공항·백화점 안내가 아닙니다. 길이 가중치는 SVG 도면 좌표의 길이로만 계산하고 미터·도보 분으로 변환하지 않습니다. 질문에 구역이 없으면 구역 연결지점별 최단 경로를 비교하며, 개별 주차칸 거리의 최적값을 의미하지 않습니다. 빈자리 보장·예약도 하지 않습니다.

## 결과 예

- 국제선 여객청사: P2 국제선
- 국내선 여객청사: P1 국내선
- 국제화물청사: P3 여객·화물
- 신세계 몰 연결 출입구: C구역
- 신세계 백화점 연결 출입구: D구역
- 신세계 B구역 → 화장실: 백화점 쪽 화장실로 경로 표시

이미지 아래 ‘입구/출구’는 ‘차량 입구/차량 출구’로 바꿨습니다. 이 차량 게이트의 좌표는 보행 그래프에 포함하지 않습니다. 실제 연결 정보가 없는 목적지(예: 공항 엘리베이터)는 확인 요청으로 처리합니다.

## 구현 및 검증

- report_lab/query.py: 목적지·출발 구역 분리
- report_lab/routing.py: 별도 시연 그래프·Dijkstra 최단 경로 계산
- policies.py: 정책 담당에서 경로 계산 호출. LLM은 거리를 만들지 않음
- chat_bridge.py: 계산한 경로를 지도 카드로 전달
- ParkingLayoutMap.jsx: 출발·도착과 붉은 점선 경로 표시
- parkon-report-lab/test_routing.py: 목적지별 순위, 출발 구역 유지, 차량 게이트 제외, 연결 경로, 실제 거리·시간 미생성 검사

API·실측 지도 연동이 준비되면 그래프의 좌표·통행 가능 여부·보행 연결을 검증된 데이터로 교체해야 합니다.
