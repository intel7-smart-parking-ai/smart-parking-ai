# 전체 아키텍처 / 미구현 초기 설계

```text
카메라 A / 카메라 B (우지원 단일 프레임 허브)
                |
      차량 탐지 / 번호 OCR / LED 인식
                |
        ROI 매핑 + 근거 이벤트
                |
     FastAPI 상태 관리·입출차·DB ------ 가상 주차장 C (D는 선택)
                |
          요금·모의 결제·매출
                |
        REST API / LLM 조회 도구
                |
     사용자 모바일 웹 / 관리자 통합관제
```

## 역할 경계

카메라 장치에 직접 접속하는 모듈은 `camera` 하나로 통일하며, AI 모델은 프레임을 전달받습니다.
모델 결과는 근거 데이터이며, 최종 입출차·결제·요금 상태는 FastAPI 서버가 결정합니다.
LED는 **모의 화재** 이벤트입니다. 실제 화재 감지가 아닙니다.

## 위치 구분

카메라 설치 위치는 미정입니다. 중앙 상단 / 모서리 상단 대각선 촬영을 비교한 뒤 확정합니다.
