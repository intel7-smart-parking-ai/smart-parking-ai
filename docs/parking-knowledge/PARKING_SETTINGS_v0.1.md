# PARK:ON 주차장 설정집 v0.1

이 문서는 이전 대화에 남은 설계를 기준 Git 커밋 `86c30692379f474bf54947efa0df22e9b96d7aa2` 위에 재구성한 자료입니다. 원본 파일을 그대로 되찾은 결과는 아닙니다.

## 사용 범위와 근거

주차장 이름·칸 번호·칸 종류는 기존 저장소의 `backend/app/chatbot/parking-chatbot/chatbot/lots.json`에서 확인했습니다. 시설 위치·인접 관계·지상/지하 구분·추천 순서는 **프로젝트 시연용 설정안**입니다. 실제 부산역·김해공항·신세계백화점의 운영 안내로 사용하지 않습니다. 인터넷 자료를 실제 확인한 것처럼 인용하지 않습니다.

정적 자료는 `parking_knowledge.v0.1.json`으로 관리합니다. 공실, 차량 위치, 요금, 경보는 저장하지 않고 서버 조회 결과를 사용합니다. API의 조회 시각과 출처를 답변에 함께 제공합니다.

## 공통 정보

- 총 156칸: A 12, B 16, C 64, D 64. 칸은 `(lot_id, space_id)`로 식별합니다.
- 시설 옆이라는 표현은 상대적 인접 관계입니다. 상세 회전 안내, 실측 거리·도보 시간은 제공하지 않습니다.
- 시설 운영 시간, 높이 제한, 칸 폭, 할인, 충전기 규격·출력·고장 상태는 미확인(`null`)입니다.
- EV 칸이 비었다고 충전기 사용 가능 또는 충전 중이 아니라고 단정하지 않습니다.
- 옥외 집결지 후보는 법정 대피소나 현재 안전한 장소로 확인되지 않았습니다. 실시간 경로 안전 정보도 없습니다.
- 현재 경보 조회가 실패·누락·잘림이면 안전하다고 답하지 않습니다. 활성/확인된 Lv2 이상 경보가 있으면 일반 주차 추천을 중단합니다.
- 빈칸 추천은 예약이 아닙니다. 조회 이후 상태가 달라질 수 있습니다.

## 질문 이해와 확인 질문

`기차주차장`, `역주차장`은 이 프로젝트의 등록 장소 범위에서 부산역주차장 후보를 나타냅니다. 별칭 문자열만 더하는 방식에 의존하지 않고, 장소 유형·방문 목적·최근 확인된 대화 맥락을 함께 해석합니다.

- “부산역 말고 공항”은 부정된 부산역을 제외하고 C로 해석합니다.
- “거기”는 최근 확인된 주차장이 있을 때만 연결합니다. 없으면 어느 주차장인지 묻습니다.
- “터미널”, “역 근처”처럼 대상이 불명확하면 후보를 설명하고 확인합니다.
- 부산역 맥락에서 “영화관”처럼 시설 설정과 충돌하면 장소 변경인지 확인합니다.
- “서울역”을 부산역으로 바꾸지 않습니다. 서비스 대상 밖이라고 설명합니다.
- 여러 주차장 비교는 복수 조회를 지원할 때만 처리합니다. 단일 의도 프로토타입은 먼저 대상을 좁혀 달라고 묻습니다.

## 갱신과 검증

시설 정보 변경 시 JSON과 문서를 함께 수정하고, 출처·버전·변경일을 기록합니다. 실제 운영에 쓰려면 시설 담당자가 배치와 운영 정보를 확인해야 합니다. 확인되지 않은 항목은 빈 문자열이나 추정값 대신 `null`로 유지합니다.

칸 종류는 서버 규격을 따릅니다. 일반 추천에 전기차·장애인 전용 칸을 섞지 않습니다. 현재 버전 추천은 일반칸만 지원하며, 전용칸의 목적지별 추천은 별도 구현 전까지 지원하지 않는다고 답합니다.
