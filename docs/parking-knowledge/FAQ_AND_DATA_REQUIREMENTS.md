## 검증 기준

1. 정적 정보에는 설정 버전과 시나리오 출처가 남아야 합니다.
2. 동적 정보는 서버 조회 시각·출처·mock 여부를 보존해야 합니다.
3. 잘린 목록이나 오래된 관측을 전체 최신 현황으로 요약하지 않습니다.
4. 차량 404를 차량 미등록으로 단정하지 않습니다.
5. 조회 실패 시 임의의 자리·요금·경보 없음으로 대체하지 않습니다.
6. 실제 모델 평가에는 각 표현 변형과 모호한 질문을 포함하고, 모의 모델 단위시험과 구분합니다.
