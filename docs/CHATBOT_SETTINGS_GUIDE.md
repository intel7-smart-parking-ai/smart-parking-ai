# 챗봇 설정집 작성 안내 (주차장·칸·시설·모의 화재)

> 상태: **틀(템플릿) — 내용은 PM이 추가 예정** (2026-11-05 11:35, PM 계획 공지 → D-55)
> 목적: 챗봇이 "영화관 가기 편한 칸", "엘리베이터 가까운 칸", "이 주차장 화재 위험", "건물 소재" 같은 질문에 **설정집에 적힌 내용만 근거로** 답하게 한다 (규칙 5).
> 담당: 내용 작성 **김한별(PM)** → 챗봇 데이터 변환·연결 **서정범·윤명수** (D-41·D-50) → (선택) 화면 표시 **김채린**
> 관련: `parking-chatbot/docs/ideas_d24.md`(만차 추천·엘리베이터 가까운 빈자리), D-24 추가 기능, `chatbot/lots.json`의 빈 칸 `facility: {underground, height_limit_m, sprinkler}`

## 0. 꼭 지킬 원칙 (내용 쓰기 전에)

1. **전부 "시연용 가상 설정"이다.** 주차장 이름이 실제 장소(부산역·신세계백화점 등)라서, 실제 시설처럼 쓰면 **사실이 아닌 정보를 퍼뜨리는 것**이 된다. 챗봇 답변에도 "(시연용 설정)"을 붙인다.
2. **화재 관련은 "모의 화재" 설정이다 (규칙 6).** 실제 화재 안전 판단처럼 쓰지 않는다.
3. **경보 중(Lv2)에는 설정집보다 대피가 먼저.** "노상이라 위험이 낮다" 같은 설정이 있어도 **경보 중에 "머물러도 된다"는 답은 절대 금지** — 위험도 정보는 평상시 질문에만 쓴다.
4. **챗봇은 설정집에 없는 것은 "설정에 없어요"라고 답한다.** 거리(미터)·소요 시간은 **실측값을 적은 경우에만** 말한다. 그렇지 않으면 "가까운 순서(순위)"만.
5. **칸 번호는 도면 번호** `(lot_id, space_id)` — 예: 가 주차장 `A-03` (D-04).
6. 설정집은 **버전**을 붙여 관리한다 (`v1`, `v2` …). 바꾸면 챗봇 담당에게 알린다.

## 1. 주차장 단위 (4곳 × 1줄)

| lot_id | 이름 | 형태 | 실내/노상 | 층 | 높이 제한(m) | 스프링클러 | 주변 주요 시설 | 출입구·출구 이름 | 비고 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| A | 개발원주차장 | 기본형 12칸 | 예: 노상 | 1 | | 예/아니오/설정 없음 | 예: 교육동 | 예: 동쪽 출구 | |
| B | 부산역주차장 | 사선형 16칸 | | | | | | | |
| C | 김해공항 주차장 (가상) | 공항형 64칸 (구역 A 24·B 36·C 4, D-57) | | | | | | | |
| D | 신세계백화점주차장 (가상) | 4구역 64칸 | 예: 실내 | 예: B1 | | | 예: 영화관·푸드코트·엘리베이터 2대 | | |

→ 챗봇 `lots.json`의 `facility`(`underground`·`height_limit_m`·`sprinkler`) 칸이 여기서 채워진다.

## 2. 시설 목록 (목적지)

| facility_id | lot_id | 이름 (답변에 쓸 말) | 종류 | 층/위치 설명 |
| --- | --- | --- | --- | --- |
| `D_elev_1` | D | 엘리베이터 1 | elevator | A구역 쪽 |
| `D_cinema` | D | 영화관 | destination | 엘리베이터 1로 6층 |
| `D_foodcourt` | D | 푸드코트 | destination | |
| `A_exit_east` | A | 동쪽 출구 | exit | |

- 종류: `elevator` / `stairs` / `entrance`(보행 출입구) / `exit`(차량 출구) / `destination`(영화관·식당·매장 등) / `charger`(충전기)
- **출구(차량)·보행 출입구·대피 출구를 섞지 않는다** (ideas_d24 주의 사항)

## 3. 칸 → 시설 가까운 순위

| lot_id | facility_id | 가까운 순서 (space_id, 앞이 가까움) | 실측 거리(선택) |
| --- | --- | --- | --- |
| D | `D_elev_1` | A-01, A-02, A-05, A-06, … | (실측했으면 m) |
| D | `D_cinema` | `D_elev_1`과 같음 | |
| A | `A_exit_east` | A-06, A-05, … | |

- 전부 쓸 필요 없음: **시설마다 가까운 칸 5~10개**면 충분
- 챗봇 답: "영화관 가기 편한 빈자리는 **A-02**예요 (엘리베이터 1 가까운 순, 시연용 설정)" — 빈자리·전용 칸 조건은 **실시간 조회 API**와 합쳐서 판단 (전기차·장애인 칸은 해당 차량에만)

## 4. 모의 화재 관련 설정

| lot_id | 화재 위험 설명 (평상시 답변용) | 건물 구성 요소·소재 (설정) | 대피 출구 | 대피 시 주의 | 소화기·소화전 위치 (설정) |
| --- | --- | --- | --- | --- | --- |
| A | 예: "노상 주차장이라 연기가 갇히지 않는 구조(설정)" | 해당 없음 | 동쪽 출구 | 차를 옮기지 않기 | |
| D | 예: "실내 지하 주차장(설정)" | 예: "천장 단열재에 불에 타기 쉬운 스티로폼 일부 포함(설정)" | 계단 2곳 | 엘리베이터 사용 금지 | |

- 이 표는 **평상시 질문**("여기 불나면 위험해?")과 **Lv2 대피 안내의 출구 이름**에만 쓴다
- Lv2 경보 중 답변 순서는 지금 그대로: **사람 먼저 → 대피 출구 → 재진입 금지 → 차량 이동 금지** (설정집 위험도와 무관)
- "위험이 낮다"는 표현은 **경보가 없을 때만**, 그리고 "시연용 설정" 표시와 함께

## 5. 자주 묻는 질문 (선택)

| 질문 예 | 답변 근거 (설정 항목) |
| --- | --- |
| 엘리베이터 가까운 자리 있어? | 3장 순위 + 실시간 빈자리 |
| 영화관 가려면 어디 세워? | 2장 영화관 → 3장 순위 |
| 여기 실내야? 높이 제한 있어? | 1장 |
| 불나면 어디로 나가? | 4장 대피 출구 |
| 여기 불나면 위험해? | 4장 위험 설명 (경보 중이면 대피 안내 먼저) |
