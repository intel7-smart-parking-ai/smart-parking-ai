**예산:** 재료비 최대 30만 원

## 프로젝트 목표

실물 주차장 2곳(카메라 2대, 미니카 총 24대)과 가상 주차장 C(필수)·D(선택)를 통합 관제합니다.
차량·번호 스티커·LED 모의화재 AI 인식과 빈자리·주차요금·모의 결제·월 매출·LLM·사용자/관리자 웹을 연동합니다.
카메라 위치, 모형 크기, ROI, 주차칸 수는 **미확정**이며 실측 후 결정합니다.
