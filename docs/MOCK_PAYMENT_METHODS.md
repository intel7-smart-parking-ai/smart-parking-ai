# 모의 결제 수단 선택

이용요금에서 차량번호 뒤 4자리 조회 → `요금 결제하기` → 신용카드 / 네이버페이 / 카카오페이 선택 → 선택 수단의 모의 결제 버튼 → 영수증 순서로 동작합니다. 선택 전에는 확정 버튼이 비활성화되며 처리 중 수단 변경·중복 클릭을 막습니다. 이전으로 돌아가거나 결제 실패 상황을 시험할 수 있습니다.

실제 PG·카드 입력·결제 앱·실제 금전 거래는 연결하지 않습니다. 금액은 기존 서버 견적을 사용하고 화면에서 재계산하지 않습니다.

독립 목업 API `POST /demo-api/v1/mock-payments`의 `payment_method`는 `credit_card`, `naver_pay`, `kakao_pay` 중 하나입니다. 생략하면 기존 클라이언트 호환을 위해 신용카드로 처리합니다. DB와 영수증·결제 내역·취소 응답에 선택 수단을 보존합니다. 같은 멱등 키로 다른 수단을 보내면 409, 미지원 수단은 422입니다. 팀 공통 API는 변경하지 않습니다.

2026-11-03 검증: 프로덕션 빌드 성공. 세 결제 수단의 저장·견적 영수증 반영·동일 키 재요청·다른 수단 충돌·취소 확인, 미지원 수단 거부, 기존 통합 점검 16개 통과. 브라우저에서 90마0022를 조회하고 카카오페이 선택→모의 결제 완료→카카오페이 영수증 표시 확인. 테스트가 만든 거래는 취소해 재시연할 수 있도록 유지했습니다.

수정: 외부 취소 후 브라우저에 남아 있던 멱등 키로 재결제하면 수단 충돌(409) 또는 취소 응답이 반환되는 문제를 해결했습니다. 수단 변경·확인된 취소에는 새 키를 사용하고, 네트워크 재시도에는 기존 키를 유지합니다. 결제 응답 직후 완료 영수증을 갱신하고 자동으로 이동하며, 실패는 버튼 바로 위에 표시합니다. 관련 회귀 테스트 포함 프론트엔드 14개 통과. 브라우저에서 0022 신용카드 결제 완료 및 서버 저장 상태를 확인했으며 이번 완료 거래는 화면 확인을 위해 유지했습니다.
