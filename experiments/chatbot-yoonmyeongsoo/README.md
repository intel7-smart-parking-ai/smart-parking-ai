# 🚗 PARK:ON 스마트 주차장 챗봇 시스템

첨부해주신 두 편의 명세 문서(`CHATBOT_QNA_YUNMYEONGSU_1106.md`, `chatbot_handoff_1106_seojeongbeom.md`)와 **주차장 도면 디자인 사진 4종(개발원, 부산역, 신세계백화점, 김해공항)**을 완벽하게 분석하여 제작한 풀스택 주차 챗봇 서비스입니다.

운영 중인 스마트 주차 웹사이트 `<시연 사이트 주소>`의 상단 `[주차 챗봇]` 탭 및 전 구역 플로팅 위젯으로 즉시 연동 가능합니다.

## 🌟 주요 특징 및 스펙 반영

### 1. 22개 질문 의도 & 7종 풍부한 카드 (Cards)
- **전기차 충전 시간 문의 (이미지 1 해결)**: 단순 빈자리 오분류를 차단하고, 충전기 실시간 잔여시간 데이터 미연동 사실을 명확히 안내하며 빈자리 확인으로 자연스럽게 유도
- **목적지 기준 최적 주차구역 안내 (이미지 2 해결)**: "김해공항 국제선 청사 가는 길 가장 가까운 구역" 질문에 도면 기반 사실인 **P2 국제선 구역 (B-01 ~ B-24, 도보 1~2분)**을 정확히 안내
- **주차장 편의시설 안내 (이미지 3 해결)**: "신세계백화점 엘리베이터 몇 개야" 질문에 도면 기반 **총 2개소(몰 A/C 상단, 백화점 B/D 상단) 및 에스컬레이터 위치**를 상세히 안내
- **항공편 탑승 & 주차 혼잡도 안내 (이미지 4 해결)**: "비행기 출발 3시간 전 도착 시 혼잡도" 질문에 공항 권장 시간(2.5~3시간 전)과 실시간 빈자리(52면)를 결합하여 안심 답변 제공
- **빈자리 조회 (`get_empty_spots`)**: 주차장별, 차종별(일반/전기차/장애인), 최상급 비교(가장 많은 곳, 신세계 vs 공항 비교), 점유율/혼잡도
- **내 차 찾기 (`find_my_car`)**: 차량 번호(23번, 1724번, 17가1724 등)로 구역 및 칸 번호(A-05 등), 주차 시간 조회
- **요금 조회 & 규정 (`get_fee`, `fee_rule`)**: 주차 시간별 요금 계산, 회차 감면, 친환경/장애인 50% 자동 할인
- **안전한 2단계 모의 결제 (`pay_fee`)**:
  - 1단계: 견적 확인 및 1회용 `confirmation_token` 발급
  - 2단계: 승인 확인 후 영수증 카드 발급 (승인번호, 15분 이내 무료 출차 안내)
  - 중복 결제 방지(`request_id` 멱등성)
- **화재 및 긴급 대피 안내 (`evacuation_guide`, `get_alerts`)**:
  - Lv2 경보 발령 시 요금 결제 자동 차단 및 비상구 유도
- **관리자 호출 & 지원 (`call_admin`, `admin_help`)**:
  - 🐞 **Q7 버그 완벽 수정**: "관리자 부르면 돈 들어?", "비용 있어?" 질문 시 호출이 즉시 접수되는 버그를 잡고, `admin_help`("관리자 호출은 전액 무료입니다")로 정확히 분기
  - 호출 시 접수번호(ADM-xxxx) 발급 및 현장 상태 카드 제공

### 2. 첨부 이미지 4종 주차장 디자인 100% 재현
- **개발원 주차장 (12면)**: A구역/B구역 세로 2열, 중앙 양방향 복도 도로, A-05/06 전기차 초록, B-06 장애인 파랑
- **부산역 주차장 (16면)**: 사선형 2열 배치(입구→출구 화살표), A-07/08 전기차, B-07/08 장애인, 비상구 픽토그램

- **김해공항 주차장 (64면)**: 국내선·국제선·국제화물 3대 청사, 순환 셔틀버스 승하차로, P1(24)·P2(24)·P3(16) 구역
- **상단 탭 바**: `[ 주차장 현황 ]`, `[ 내 차 찾기 ]`, `[ 요금 결제 ]`, `[ 안전 안내 ]`, `[ 주차 챗봇 ]`
- **구역별 빈자리 요약 카드 & 4대 필터**: `[전체 보기]`, `[빈자리]`, `[전기차]`, `[장애인]`

## 🚀 실행 및 확인 방법

### 방법 1. 웹 브라우저에서 즉시 열기 (서버 없이도 100% 작동)
`frontend/index.html` 파일을 더블 클릭하여 크롬이나 엣지 브라우저에서 바로 여시면 됩니다.
- 주차장 4곳의 도면을 직접 확인하고 상단 `[ 주차 챗봇 ]` 탭 또는 우측 하단 🤖 아이콘을 클릭하여 챗봇을 즉시 테스트할 수 있습니다.
- 오프라인/스탠드얼론 모드가 내장되어 있어 백엔드가 없어도 100% 동작합니다.

### 방법 2. Python 백엔드 서버 구동
```bash
# 1. 패키지 설치
pip install fastapi uvicorn pydantic

# 2. 서버 실행
python run.py
```
- 접속 주소: `http://localhost:8080`
- 챗봇 API: `http://localhost:8080/api/v1/chat`

## 🌐 <시연 사이트 주소> 에 챗봇 기능 넣는 방법

### 1) 가장 간단한 방법 (원클릭 embed.js 추가)
운영 중인 웹 서버의 `index.html`에 아래 태그를 `</body>` 바로 위에 추가합니다:
```html
<script src="/embed.js"></script>
```
- 사이트 우측 하단에 플로팅 챗봇 버튼이 나타나며,
- 상단 메뉴의 `[주차 챗봇]` 버튼과도 자동으로 연동되어 팝업 창이 열립니다!

### 2) 기존 웹사이트 개발자 도구(F12) 콘솔에서 즉시 테스트
지금 바로 `<시연 사이트 주소>`에 접속한 후, 브라우저 콘솔(`F12` -> `Console`)에 `frontend/embed.js`의 전체 내용을 복사해서 붙여넣고 엔터를 치면 사이트에 즉시 챗봇이 뜹니다!
