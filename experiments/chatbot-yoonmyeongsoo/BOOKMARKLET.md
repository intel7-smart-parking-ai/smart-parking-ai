# 🔖 PARK:ON 주차 챗봇 원클릭 북마클릿 (Bookmarklet)

운영 사이트(`<시연 사이트 주소>`)의 소스 코드를 서버에서 직접 수정하지 않고도, **브라우저 즐겨찾기(북마크) 클릭 한 번으로 사이트에 챗봇을 즉시 띄울 수 있는** 도구입니다.

---

## 📌 북마클릿 등록 방법 (1분 소요)

1. 크롬(Chrome) 또는 엣지(Edge) 브라우저를 엽니다.
2. 아무 웹페이지나 **북마크(즐겨찾기)**에 추가합니다. (단축키: `Ctrl + D`)
3. 추가한 북마크를 마우스 오른쪽 버튼으로 클릭하고 **[수정]**(또는 [속성])을 선택합니다.
4. **이름**: `PARK:ON 챗봇`
5. **URL (주소)**란에 아래의 한 줄 자바스크립트 코드를 그대로 복사해서 붙여넣고 저장합니다:

```javascript
javascript:(function(){if(window.__PARKON_CHATBOT_INITIALIZED__){alert("PARK:ON 챗봇이 이미 실행 중입니다.");return;}const s=document.createElement("script");s.src="https://cdn.jsdelivr.net/gh/m258k/parkinggood@main/frontend/embed.js";s.onerror=function(){/* CDN 경로 대신 로컬 인라인 스크립트 실행 */const script=document.createElement("script");script.textContent=`${localStorage.getItem('parkon_embed_code')||''}`;document.body.appendChild(script);};document.body.appendChild(s);})();
```

## 💡 브라우저 콘솔에서 즉시 띄우기 (F12)

1. `<시연 사이트 주소>` 접속
2. 키보드 `F12` 키를 눌러 개발자 도구를 열고 `Console` 탭 클릭
3. [`frontend/embed.js`](file:///c:/Users/m258k/OneDrive/Desktop/parkinggood/frontend/embed.js)의 전체 코드를 복사하여 콘솔에 붙여넣고 `Enter`
4. 사이트 우측 하단에 **🤖 파란색 플로팅 버튼**이 즉시 나타나며, 상단 **`[주차 챗봇]`** 메뉴 버튼을 눌러도 챗봇 창이 바로 열립니다!

## 🧪 테스트 추천 질문 목록

- **질문 1 (신규)**: `전 주차장 빈자리 확인` 또는 `주차장 빈자리`
  - ➔ 4개 주차장(개발원, 부산역, 김해공항, 신세계) 실시간 잔여석 카드가 나타나며, 각 주차장별 **[🗺️ 도면 확인]** 버튼을 누르면 해당 도면으로 즉시 전환됩니다.
- **질문 2 (신규)**: `전기차 충전 현황` 또는 `충전 시간 얼마나 남았어?`
  - ➔ 각 충전기의 **배터리 잔여율(%)**, **완충까지 남은 시간(분)**, **충전 출력(kW)**이 2열 콤팩트 그리드로 한눈에 정렬되며 주차장별 탭 필터링이 가능합니다.
- **질문 3**: `김해 공항 주차장에서 국제선 청사로 가는길이 가장 가까운 주차구역이 어디야?`
  - ➔ P2 국제선 구역(B-01~24, 도보 1~2분) 및 셔틀버스 승하차로 안내
- **질문 4**: `신세계백화점 엘리베이터 몇개야`
  - ➔ 도면 기준 총 2개소(몰 A/C 상단, 백화점 B/D 상단) 및 에스컬레이터 위치 안내
- **질문 5**: `비행기가 2시20분 출발인데 3시간전에 도착해도 혼잡하지 않을까?`
  - ➔ 공항 수속 권장 시간(2.5~3시간 전) 및 실시간 김해공항 잔여석(52면) 안심 안내
- **질문 6**: `관리자 부르면 돈 들어?`
  - ➔ Q7 버그 패치: 관리자 호출이 즉시 접수되지 않고, "전액 무료입니다" 친절 답변
- **질문 7**: `23번 차 요금 얼마야?` -> `결제해줘`
  - ➔ 1,500원 요금 청구서 카드 -> 확인 토큰 발급 -> 결제 승인 영수증 카드
- **질문 8**: `내 차 어디 있어?` 또는 `23번 차 어디야?`
  - ➔ 개발원 A-05 주차칸 위치 안내 및 주차 도면 연동
