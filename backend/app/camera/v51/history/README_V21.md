# V21 주차장 통합 자동 수집 프로그램



V20의 스티커 판독·근거 검증 문제를 수정하고 **칸 자동 등록, 칸명 표시사진·한글 JSON, 자동 저장, 실제 내보내기 수량**을 추가한 V21입니다. 카메라 한 대로 A 직사각형12칸/B 사선16칸을 순서대로 촬영합니다. 색은 스티커 배경색입니다.



`run_windows.bat` 실행 → 주차장 선택 → **자동 수집 시작**. 전칸 이름과 닫힌 주차선이 읽히면 연결·등록·판독·저장을 진행합니다. 저장한 구도는 매 분석 장면과 대조합니다. 미확인은 보류하고 파일 오류는 정상 완료 수량에 넣지 않습니다.



- 칸명 폴더에 같은 이름의 표시사진 PNG와 한글·수치 JSON을 저장합니다. 전체 표시사진과 무표시 원본도 보존합니다.

- 화면에서 원본·칸별 쌍·미확인·화질주의·내보낸 이미지/JSON 수와 경로를 확인합니다.

- 자동 후보 저장과 내보내기는 사람 승인 없이 가능하며, 사람 검수 정답은 별도로 관리합니다.

- 최종 회귀152개 통과. 실제 로컬 CPU OCR로 합성 A12/B16 등록, 사진·JSON28쌍과 이미지32/데이터JSON30 내보내기를 확인했습니다.



실물 D39 A/B 사진이 없어 현장 정확도는 미검증입니다. 자동 등록에는 보이는 칸 이름·닫힌 경계가 필요합니다. 학습된 점유 모델이 없으면 스티커 없는 칸은 빈칸 대신 관측 보류입니다. 차량 마스크 기반 잘못된 위치의 확정 판정은 포함하지 않습니다.
