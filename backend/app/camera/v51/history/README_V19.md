# V19 주차장 통합 수집 프로그램



V18의 분리된 수집·검수 화면을 **카메라 1대, A·B 주차장 순차 촬영용 통합 화면**으로 확장했습니다. A는 직사각형 12칸, B는 사선 16칸을 네 모서리 ROI로 등록합니다. 주차선을 자동으로 찾아내는 모델은 아닙니다.



**실행:** `run_windows.bat` 더블클릭. 자세한 순서는 START_HERE.md (`START_HERE.md`, 별도 보관 이력)를 보세요.



- 전체 원본 영상과 모든 칸 카드, 점유·번호·스티커 배경색 후보, 선택 칸 검수, 저장 경로·수량을 한 창에 표시합니다.

- 빈 기준 영상과의 차이를 사용하는 A안, 학습 모델을 연결하는 B안, 수동 검수를 선택합니다. B안 학습 모델은 포함하지 않습니다.

- 자동 후보와 사람이 승인한 정답을 분리합니다. 정답과 예측의 불일치도 선택 칸에 표시합니다.

- 원본·칸 크롭·스티커 크롭·라벨을 구분 집계하고, 저장 실패·파일 손상·검수 충돌을 표시합니다.

- 승인 자료만 점유·번호·색 작업별로 내보내며 같은 촬영 배치는 같은 학습/검증/시험 분할을 사용합니다.

- 분석, 파일 저장, 카메라 수신을 별도 스레드에서 처리하고 분석 대기열이 계속 쌓이지 않도록 제한합니다. 실제 FPS 향상을 측정했다는 뜻은 아닙니다.



**범위:** 색은 차체색이 아닌 스티커 배경색입니다. 전용칸 종류 불일치와 경계 변화 후보를 표시하지만 차량 마스크 기반 불법주차 확정 기능은 아닙니다. 자동 결과는 검수 전까지 학습 정답이 아닙니다. 좋은 데이터 품질은 촬영·검수 과정에서 확인해야 합니다.



변경·검증 이력 (`CHANGELOG.md`, 별도 보관 이력) · 요구사항 구현 대응표 (`IMPLEMENTATION_STATUS.md`, 별도 보관 이력) · 검증 결과 (`VALIDATION.json`, 별도 보관 이력) · 설계 기준 문서 (`PARKING_DATASET_INTEGRATED_UI_REQUIREMENTS_2026-11-04.md`, 별도 보관 이력)



검증: V19 전용 52개 테스트 통과, 실제 EasyOCR CPU로 합성 숫자 23 인식 확인. 실물 카메라 연결·야외/실내 정확도·B안 학습 모델·실제 서버·장시간 수집·화면의 육안 검수는 미검증입니다. 이전 버전의 테스트 결과는 `history/`에 보존하며 V19 통과 수에 합산하지 않습니다.
