# V23 → V24 변경 이력



2026-11-05. 기존 V23 배포를 보존한 별도 수정본입니다. 전체 코드 검수 중 재현한 오류와 색상 처리 비용을 보완했습니다.



## 수정 내용



| 구분 | V23에서 재현한 문제 | V24 수정 |

|---|---|---|

| 사진→카메라 전환 | 최초 카메라 연결에서 이전 사진·ROI·장면이 남고 미저장 정답 확인을 건너뜀 | 새 연결/기존 연결 모두 전환 확인 후 이전 장면·ROI·확인상태 초기화 |

| 자동 등록 중 수동 분석 | 같은 작업자가 등록하는 동안 1회 분석을 요청할 수 있어 사진 자동 흐름과 경쟁 | 등록 완료 전 수동 분석 요청 차단 |

| 중단 후 재저장 | pending으로 약속된 예측 파일이 없을 때 None으로 취급해 재저장 | complete/pending의 필수 예측 유실을 동일하게 거부 |

| 검수 후 파생 자료 | 손상·유실된 예측을 무시하고 완성 사진/JSON으로 생성 | 사람 정답은 보존, 파생 묶음은 partial로 남기고 복구 전 내보내기 차단 |

| 내보내기 검증 | 입력 해시만 맞으면 잘못된 예측 내용도 통과 가능 | 최신 예측 계약/장면 일치 검증과 pending 상태 차단 추가 |

| 스티커 후속 발견 | 번호 OCR이 스티커와 번호를 찾아도 점유가 unknown으로 남음 | 스티커 근거 모드에서 해당 근거를 점유 후보·전용칸 비교에 반영 |

| ROI 입력 검증 | 소수 문자 좌표 또는 수동 전환 후 틀어진 ㄷ자 경계 근거가 통과 | 정수 픽셀과 실제3면/입구 경계를 등록 방식과 관계없이 검사 |

| 점유 모델 설정 | 잘못된 threshold/size/std 등이 모델 실행 단계까지 전달 | 설정 로드·UI 적용·추론 진입에서 전처리와 임계값 선검사 |

| 색상 처리 효율 | 작은 스티커마다 전체 고해상도 영상 HSV와 마스크를 반복 생성 | 스티커 주변으로 처리 영역 축소, 가장자리 침식 결과는 보존 |



## 실제 실행한 검증



- 회귀 **231개 통과**: 기존215+신규16, 실패·오류·건너뜀0.

- 별도 저장중단 **28곳 통과**: 재저장16/검수12. 원본보존·불완전 내보내기 차단·복구 수량 확인.

- V23 신규 재현16 메서드에서 하위사례 포함 실패18/오류5; 같은 코드의 V24는 모두 통과. 이 수치를 독립 결함23개로 해석하지 않습니다.

- 사용자 빈 A/B 원본 재처리: A12/B16 ㄷ자 좌표 유지, 추론오류0, 칸28쌍, 내보내기 이미지32·데이터JSON30·원본2. OCR은 V23 실제 CPU 관측35회 재사용이며 이번 새 OCR 성능 시험이 아닙니다.

- 과거 합성171파일·V23사진169파일 총340개 해시 불변.

- 색상함수 출력 일치. 4000×3000 합성 네영역×5회에서 중앙값 약492ms→1.10ms. 전체 프로그램 속도 향상 비율이 아닙니다.

- main --check, AST/JSON 파싱, V23 소스150파일/ZIP 보존, 배포 ZIP CRC·SHA256은 VALIDATION/PACKAGE_CHECK_V24에 기록합니다.
