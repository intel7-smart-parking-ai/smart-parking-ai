# V24 주차장 통합 자동 수집 프로그램



V23에서 **사진→카메라 전환 시 이전 장면 잔존, 손상·유실된 예측을 포함한 자료의 완료 처리, 후속 스티커의 점유 반영 누락**을 수정한 V24입니다. 자동등록 중 분석 경쟁, ROI/모델 설정 검증과 색상 처리 효율도 보완했습니다.



`smart-parking-v24.zip`을 새 폴더에 풀고 `smart_parking_v24/run_windows.bat`를 실행하세요. A12/B16 선택 후 카메라는 **자동 수집 시작**, 사진은 **사진 자동 등록·수집**을 사용합니다. 데모는 `run_demo.bat`입니다. 실제 ㄷ자3면과 입구 가상점선, 칸별 한글 JSON/표시사진, 원본보존·수량·내보내기를 유지합니다.



전체 회귀231개·저장중단28곳 통과. 기존자료340파일 불변. 제공한 빈 사진은 A12/B16 등록·28쌍 저장·내보내기를 재확인했습니다. 이 사진 검증의 OCR은 V23의 실제 CPU 관측을 재사용했습니다. 실차 번호/색 정확도는 아직 미측정입니다.



V23 소스/ZIP과 촬영 자료는 보존했습니다. **저장 폴더 선택**으로 이전 데이터 루트를 이어 사용할 수 있으며 데이터 형식은 변경하지 않았습니다. 예측이 손상/유실된 묶음은 사람 정답을 보존하면서 내보내기를 차단하므로 설명서의 복구 절차를 확인하세요.
