# V23 주차장 통합 자동 수집 프로그램



V22에서 **A주차장 12칸이 보이지 않던 표시 문제와 열린 주차선 등록 제한을 수정한 V23**입니다. 제공된 A 직사각형 12칸·B 사선 16칸 사진에 맞춰 실제 ㄷ자 선 3면을 찾고, 열린 입구는 별도의 가상 경계로 처리합니다.



`smart-parking-v23.zip`을 새 폴더에 풀고 `smart_parking_v23/run_windows.bat`를 실행하세요. A/B 선택 후 **사진 자동 등록·수집**으로 사진 한 장을 선택하면 칸 등록 → 점유 근거·번호·스티커색 분석 → 사진·한글 JSON 저장을 진행합니다. 실제 카메라는 **자동 수집 시작**을 사용합니다. `run_demo.bat`는 A12/B16 합성 체험입니다.



- 실제 선 3개는 실선, 입구의 계산용 경계는 주황 점선으로 구분합니다. 원본에 없는 선을 실제 주차선으로 저장하지 않습니다.

- A/B를 바꾸면 이전 사진·상세 번호를 지우고 해당 주차장 배치를 표시합니다. 과거 자료는 **저장 폴더 선택 → A/B → 선택 주차장 저장 장면 보기**로 엽니다.

- 칸명 폴더에 같은 이름의 표시사진 PNG·한글/수치 JSON을 저장하며 무표시 원본·학습 크롭도 별도 보존합니다.

- UI에서 저장 수량·누락·미확인·내보낸 사진/JSON 수와 경로를 확인합니다. 저장 중단 방어와 복구 기능은 유지했습니다.

- 회귀시험 **215개 통과**. 제공된 빈 주차장 사진 2장으로 A12/B16 등록, 실제 CPU OCR, **28쌍 저장 / 이미지32·데이터JSON30 내보내기**를 확인했습니다.



두 사진에는 차량이 없습니다. 따라서 실제 차량 번호·색 정확도와 위치 위반 판정 성능은 아직 측정하지 못했습니다. 점유 모델 없는 스티커 방식은 근거가 없으면 ‘관측 보류’로 남깁니다. UI 화면 조작 검사는 사용자 Esc 입력으로 중단됐으며 A/B 전환은 숨긴 Tk 자동 시험으로 확인했습니다.
