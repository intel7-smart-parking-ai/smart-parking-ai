# V11 → V12 스티커 편집 개선



## 확인된 V11 문제



1. 전체 영상을 화면 크기로 축소해 보여주고 확대·이동 조작을 제공하지 않았습니다. 작은 스티커는 클릭 오차가 생기기 쉬웠습니다.

2. 선택한 점을 빨간 원으로만 표시했습니다. 클릭 번호와 연결선이 없어 순서나 교차 여부를 보기 어려웠습니다. 잘못된 영역 검사는 완료를 누른 뒤에만 나타났습니다.

3. 스티커 편집에도 주차칸 등록 안내를 재사용해 ‘등록 0/12칸 · 현재 A-01’이 나왔습니다. 이 표시는 잘못된 UI 안내이며, 그 자체가 검수 대상 칸을 A-01로 바꾸는 것은 아닙니다.

4. 스티커 위치와 주차칸 전체 위치를 같은 축척으로 다뤄 사진마다 작은 점 네 개를 반복 지정해야 했습니다. 원본이 흐릿하면 확대하더라도 세부 정보가 새로 생기는 것은 아닙니다.



## V12 수정



- 스티커 편집을 열면 검수 중인 주차칸 주변을 자동 확대합니다. ‘선택 칸 확대’로 되돌릴 수 있습니다.

- ‘확대 +’, ‘축소 −’, ‘전체 보기’ 버튼 및 마우스 휠 확대/축소를 추가했습니다.

- 오른쪽 마우스 버튼을 누른 채 드래그하면 확대된 화면을 이동합니다.

- 화면 표시 크기와 원본 좌표를 분리했습니다. 확대·이동 중 클릭해도 원본 이미지 좌표를 저장하며 기존 점은 화면 배율을 바꿔도 유지됩니다. 전체 확대 비트맵 대신 고정 크기 화면 영역을 렌더링합니다.

- 점마다 1~4 번호와 주황색 연결선을 표시합니다. 네 점이면 마지막 점에서 첫 점까지 닫습니다.

- 스티커 편집은 ‘스티커 내부 선택점 n/4’, 번호판 박스 편집은 ‘번호판 박스 선택점 n/2’, 주차칸 편집은 해당 칸 등록 안내로 구분했습니다.

- 네 점이 교차하거나 유효하지 않으면 하단에 오류를 표시합니다. 저장 전 영역 검증도 유지합니다.



주요 수정 파일: widgets.py(편집·좌표 변환·검수 연결), main.py(V12 제목), tests/test_v9_gui.py(회귀 시험). 번호 01~99 및 100, Intel XPU 경로, 스티커 내부 색 측정 규칙은 동일합니다. 자료 규칙은 1103-sticker-100-v2이며 UI 변경만으로 올리지 않았습니다.



## 사용 순서



1. 검수 화면에서 해당 칸을 선택하고 ‘스티커 내부 네 모서리 지정 + 색 측정’을 누릅니다.

2. 선택 칸 주변이 확대되어 보입니다. 스티커 위에 마우스를 놓고 휠을 올려 추가 확대하세요.

3. 위치가 벗어나면 오른쪽 버튼을 누르고 드래그하세요. ‘전체 보기’로 사진 전체를 다시 볼 수 있습니다.

4. 바닥·차체를 제외하고 스티커 테두리 안쪽을 시계 방향 또는 반시계 방향으로 네 번 클릭합니다. 연결선이 교차하지 않도록 하세요.

5. 잘못 찍었으면 ‘점 취소’로 마지막 점부터 되돌립니다. 네 점과 연결선을 확인한 뒤 ‘완료’를 누릅니다.

6. 검수 화면에서 대상 칸·측정 색·번호를 확인하고 승인 저장합니다. 완료 버튼만으로 최종 검수 파일이 승인 저장되는 것은 아닙니다.



## 설치와 데이터 이전



V12 ZIP을 별도 폴더에 풀고 main.py가 있는 폴더에서 PowerShell을 여세요. 기존 V10 가상환경이 복원된 경로에 있다면 다음 명령으로 재설치 없이 실행할 수 있습니다.



```powershell

& '<local-path> .\main.py

```



가상환경 경로의 폴더를 삭제/이동하면 위 명령이 실패합니다. 새 환경이 필요할 때만 install_intel_gpu.bat를 사용하세요.



기존 models를 V12로 복사하면 모델 재다운로드를 줄입니다. 기존 cameras.json, camera_quality.json과 configs 폴더를 복사하면 장치 설정과 등록 ROI를 이어 쓸 수 있습니다. datasets를 복사하거나 config.json의 dataset_directory를 기존 자료 절대 경로로 지정하면 기존 사진·검수를 이어갑니다. 프로그램을 같은 데이터셋으로 동시에 실행하지 마세요. V11과 V12의 규칙은 같으므로 버전 변경만으로 기존 검수의 재승인을 요구하지 않습니다.



## 검증과 한계



기존 69개 + 신규 GUI 회귀 4개, 총 73개 시험 통과. 실패·오류·건너뜀 0. 확대·이동 후 원본 좌표 저장, 배율 변경 후 선택점 유지, 네 점 닫힌 연결선, 스티커 전용 안내, 교차점 차단, 선택 칸 확대와 배율 범위를 시험했습니다. Python 구문 및 main.py --check 검사를 통과했습니다.



실제 D435 촬영과 실제 마우스 휠/드래그의 현장 사용감, DPI별 화면 배치는 추가 확인이 필요합니다. 시험은 실제 Tk 위젯과 합성 이미지/이벤트로 수행했습니다. 확대는 표시 조작 개선이며 원본 화질이나 OCR 인식률 향상을 실측한 결과가 아닙니다. 스티커 영역은 사진마다 직접 지정해야 합니다.
