# V22 주차장 통합 자동 수집 프로그램



V21에서 저장 중단 후 이전 라벨 사진이 내보내지는 문제와 자동 칸 등록 상태 정체를 수정한 V22입니다. 검수 번호 정규화, 최신 예측/정답 지문 검사, **선택 장면 저장 복구**, 내보내기 상태·화면 배치를 보완했습니다.



`smart-parking-v22.zip`을 새 폴더에 풀고 `smart_parking_v22/run_windows.bat` 실행 → 주차장 선택 → **자동 수집 시작**. 카메라 한 대로 A 직사각형12칸/B 사선16칸을 순서대로 촬영합니다. 색은 스티커 배경색입니다.



- 전칸 이름·닫힌 경계가 읽히면 칸 등록, 번호·색 분석, 자동 저장을 진행합니다.

- 칸명 폴더에 표시사진 PNG와 한글·수치 JSON을 같은 이름으로 저장하고 무표시 원본을 보존합니다.

- UI에서 수량·미확인·화질주의·오류·내보낸 이미지/JSON 수와 경로를 확인합니다.

- 갱신 미완료 자료와 최신 예측/정답이 다른 사진 묶음은 내보내지 않습니다. 저장 복구는 기존 증거로 파생 자료를 다시 만듭니다.

- 최종 회귀 **182개 통과** 및 별도 저장 중단 **28곳 통과**. 현재 PC에서 합성 자료를 표시한 실제 UI도 확인했습니다.



V21 소스/ZIP과 촬영 데이터를 보존했습니다. V21 데이터 루트를 이어 쓸 수 있지만 이전 표시사진 묶음은 목록에서 **선택 장면 저장 복구** 후 V22 자동 내보내기를 사용합니다. V22에서 갱신한 자료를 V21로 수정하지 않습니다. 같은 데이터 루트는 한 프로그램에서만 수정합니다.



현행 D39 실물 A/B 영상이 없어 현장 정확도는 미검증입니다. 학습된 점유 모델이 없을 때 스티커 없는 칸은 관측 보류이며, 차량 마스크 기반 위치 위반 확정 모델은 포함하지 않습니다. 이전 V21의 실제 CPU OCR 합성 결과는 history에 보존했고 이번 V22 인식 성능 재측정으로 주장하지 않습니다.
