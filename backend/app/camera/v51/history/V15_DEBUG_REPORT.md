# V14 → V15 디버깅 결과



## 확인된 문제와 수정



| 문제 | V15 수정 |

|---|---|

| 자동 노출 중 수동 노출·게인이 읽기 전용으로 표시되는 경우, 자동을 해제하려는 요청도 미리 거부됨. UI도 해당 값을 빼버려 수동 전환 불가 | 자동 해제와 함께 들어온 수동 값을 보존하고, 범위 검사 후 자동 해제부터 수행. 영구 읽기 전용인 경우 실제 SDK 실패로 안내 |

| 설정 쓰기는 성공했으나 실제값 재조회가 실패해도 성공으로 반환될 수 있음 | 요청 항목의 실제값 조회 실패를 오류로 처리하고 설정 저장 차단 |

| 닫은 설정 창의 대기 요청 또는 연결이 끊긴 시점의 대기 요청이 뒤늦게 적용될 수 있음 | X 닫기 동작에 타이머 해제·대기 요청 취소를 연결. 작업 스레드는 취소 요청을 건너뛰고 연결 종료 때 남은 요청을 오류 처리 |

| 설정 창이 열려 있는데 위치 확인과 수집을 다시 시작할 수 있음 | 해당 카메라 설정 창을 닫기 전에는 위치 확인·촬영 차단. 같은 카메라의 설정 창 중복도 방지 |

| 카메라 설정 창 안의 원본 확대창은 앱 종료 검사에서 누락 | 중첩 편집창까지 찾아 완료/취소 전 앱 종료 보류 |

| Windows에서 파일 교체 시 일시적 PermissionError가 나면 저장 실패 | 원자적 JSON 교체에서 PermissionError만 최대 5회 시도. 계속 실패하면 오류를 전달하며 이전 파일을 성공으로 처리하지 않음 |



마지막 항목은 실제 시험 중 WinError 5가 한 번 발생해 확인했습니다. 원인이 OneDrive/백신/다른 프로세스인지까지 확정하지는 않았습니다. 재시도 총 대기 시간은 최대 약 0.2초이며 영구 권한 문제를 해결하는 기능은 아닙니다.



수정 파일: quality.py, camera_tools.py, camera_hub.py, main.py, parking_ai/storage.py. 테스트는 tests/test_v15.py와 tests/test_v9_gui.py에 추가했습니다.



## 실제 검증



- 수정 전 V14 코드에 새 회귀 사례 8개를 적용해 실패 2개·오류 6개를 확인했습니다. 신규 동작/상태가 없어서 발생하는 오류도 포함되므로 독립 버그 8개라는 뜻은 아닙니다. 결과는 V14_REPRODUCTION.json에 보존했습니다.

- 수정 후 기존 88개 + 신규 8개 = 총 96개 테스트 통과. 실패·오류·건너뜀 0.

- 새 시험은 자동→수동 전환, 실제값 조회 실패, 닫기 버튼의 요청 취소, 작업 스레드의 취소/연결 종료 처리, 설정 중 촬영 차단, 일시적인 파일 잠금 재시도를 확인했습니다.

- Python 구문 검사, main.py --check, ZIP CRC/포함 파일 일치 확인.

- V14 소스 파일을 작업 전 SHA-256과 대조해 수정하지 않았음을 확인했습니다. 기준값은 V14_BASELINE_HASHES.json에 있습니다.



모든 자동 검증은 가짜 SDK 센서·합성 프레임·실제 Tk 창으로 수행했습니다. 실제 D435 설정 적용, 장치별 수동 제어 가능 범위, 장시간 재연결, 실제 OCR·색상 정답률은 현장 확인이 필요합니다. 이미 장치에서 실행을 시작한 설정은 창을 닫아도 되돌릴 수 없습니다. 실패 후에는 실제값을 다시 조회하세요.



## 실행 순서



1. V15 ZIP을 별도 폴더에 풉니다. 기존 V14 파일을 덮어쓰지 않습니다.

2. 기존 모델(models), 카메라 설정(cameras.json, camera_quality.json), 등록 ROI(configs)를 필요에 따라 복사합니다. 데이터셋은 복사하거나 config.json의 dataset_directory를 기존 경로로 지정할 수 있습니다. 같은 데이터셋으로 두 버전을 동시에 실행하지 마세요.

3. V15의 main.py가 있는 폴더에서 터미널을 열고 다음 명령을 실행합니다. V10 가상환경 폴더가 기존 위치에 있어야 합니다.



```powershell

& '<local-path> .\main.py

```



4. 카메라 연결 → 해당 카메라 ‘화질·카메라 설정 / 원본 확대’ → 현재값 조회 → 자동 상태 확인 → 필요하면 자동을 해제하고 수동 값 적용.

5. 실제값을 확인한 뒤 ‘적용 후 설정 저장’. 요청 처리 중에는 완료 응답을 기다리세요. 실패했다면 조회를 다시 해 실제 상태부터 확인합니다.

6. 원본 확대·선택 영역 화질 확인으로 가까운 칸과 먼 칸을 비교합니다. 조정 절차·지표 해석은 V14_CHANGES.md에 있습니다.

7. 확대창을 닫고 설정 창도 닫기 → 위치 확인 → 한 장 저장 → OCR → 여러 차량 결과·칸별 검수.



제품 버전은 V15이며 자료 규칙 1103-sticker-100-v2와 frame_revision=multi-slot-v1은 유지합니다. V14와 데이터 규칙이 같아 이번 수정 때문에 기존 승인 자료를 다시 승인할 필요는 없습니다.
