# V18 → V19



작성일: 2026-11-04. 제품 버전: V19.



## 수정 이유



V18은 수집·검수가 분리된 기존 화면이고 단일 카메라로 A 직사각형 12칸과 B 사선 16칸을 순차 수집하며 모든 결과와 저장 현황을 함께 보는 요구를 충족하지 못했습니다. 사용자가 확정한 단일 카메라·스티커색·D-39 기준에 맞춰 통합 수집 흐름을 구현했습니다. V18 원본 소스와 ZIP은 덮어쓰지 않습니다.



## 실제 변경



1. 새 단일 화면에 원본, 전칸 카드, 번호/색/점유 후보, 정답 검수, 저장 현황과 재열기를 배치했습니다. 작은 높이에서 검수 영역은 스크롤합니다.

2. 전체 ROI 등록을 수집 조건으로 만들고, 사선 다각형 마스킹·주차장별 구도 구분·재연결 시 재확인을 적용했습니다.

3. 빈 기준 A안, 모델 미등록 시 보류하는 B안 2분류 연결, 수동 모드를 추가했습니다. 차량 경계 확정 대신 근거에 맞는 변화 후보를 표시합니다.

4. 원본과 예측 프레임을 묶고, 설정 변경 후 늦게 도착한 결과를 버립니다. 재연결 확인은 예전 고정 화면이 아니라 현재 프레임을 사용합니다.

5. 원본·칸·스티커·예측·자산 영수증을 저장하고 같은 장면 재시도 중복을 막았습니다. 다른 원본 픽셀로 기존 장면을 덮어쓰지 않습니다. 예측 수정 이력을 보존합니다.

6. 실제 파일/해시 기반 수량, 부분 실패·손상, 승인 항목별 수량을 표시합니다. 검수 JSON 오류가 유효 원본을 집계에서 숨기지 않도록 했습니다.

7. 예측은 정답과 분리하고 검수 충돌을 검사합니다. 승인 저장 실패 시 승인 완료로 표시하지 않습니다.

8. 승인 크롭을 작업별로 내보내고 배치별 분할 및 동일 원본 분할 누수를 검사합니다. V18의 원본/표시사진 내보내기도 유지했습니다.

9. D-39 번호 정책과 D=64 참고 레이아웃을 반영해 데이터 계약을 `20261104-d39-v3`으로 변경했습니다. 제품 버전 때문에 pose를 바꾸지 않았습니다.

10. 선택형 API 송신을 별도 스레드로 추가했습니다. 기본 꺼짐이며 실제 서버에 접속하지 않았습니다.

- `run_tests.py --report ...`: **52개 통과, 실패/오류/건너뜀 0**. 사선/직사각형, D-39, 기준 불일치·검은 화면·모델 없음, 데이터 저장/손상/재시도, 검수 분리/충돌, 분할 내보내기, Tk 상태/종료, 모의 HTTP 재시도/만료를 검증했습니다.

- 전체 B 사선 16칸의 분석 → 원본/16크롭 저장 → 선택 칸 승인 → 학습 크롭 내보내기 통과. 모든 입력은 합성 시험 자료입니다.

- `main.py --check`: A12/B16/C12/D64 및 단일 카메라 설정 통과. 장치를 열지 않는 검사입니다.

- EasyOCR 1.7.2 / Torch 2.15.0+xpu 환경에서 **CPU**로 합성 숫자 23 인식, 점수 약 0.968, 로딩 포함 약 4.58초. 실제 차량 정확도나 FPS가 아닙니다.

- OCR 첫 실행은 샌드박스의 Torch DLL 접근 제한이 있었고 승인된 로컬 재실행에서 성공했습니다. GUI 반복 시험 중 이전 Tk 객체가 작업 스레드에서 정리되는 시험 수명 문제가 있어 테스트 종료 정리를 메인 스레드로 수정하고 전체 52개를 다시 통과했습니다.

- 기존 V18 기준 해시 대조 및 ZIP 배포 검사 결과는 `VALIDATION.json`과 동봉 보고서에 기록합니다. 과거 V18의 134개 결과를 V19 결과로 합산하지 않습니다.



## 미검증·제한



실물 RealSense 연결·정확도·촬영 품질, 실제 OpenVINO 모델, GPU 성능, Geti 가져오기, 실제 서버, 장시간 수집 및 UI의 육안 확인은 미검증입니다. UI 미리보기 도중 장치 열거에서 RealSense named mutex 오류가 관측되었으며 실제 장치 검증 완료로 처리하지 않았습니다. 카메라 연결 오류가 나면 SDK/다른 점유 프로세스/USB 상태를 현장에서 확인해야 합니다. 테스트는 장비 없는 합성 조건에서 수행했습니다.



이 버전은 자동 주차선 검출, 차량 마스크 기반 위반 확정, 자동 학습, 전체 평가셋 성능 리포트, 서버 최종 세션 조회를 포함하지 않습니다. 학습 모델과 실물 데이터 준비가 필요합니다.
