# V22 → V23 변경 이력



날짜: 2026-11-04. 이전 배포를 덮어쓰지 않은 한 묶음의 실제 기능/디버깅 수정입니다.



## 수정 이유와 변경 사항



1. A12가 보이지 않음: B 고정 데모를 A/B 공통 생성기로 변경하고 A12 기본 시작, A6열/B8열 카드, 빈 화면 배치를 추가했습니다.

2. B→A에서 이전 B 사진·상세 번호 잔존: 입력·선택·상세·예측을 함께 초기화하고 늦은 결과를 차단했습니다.

3. 과거 데이터 확인: 주차장별 최신 정상 장면을 읽고 손상/누락을 표시하는 저장 장면 로더를 추가했습니다.

4. 사용자 사진에서 열린 선과 회전 이름 실패: ㄷ자 세 면 탐색, 회전/다중 크기 이름 OCR, 원본 좌표 역변환, 입구 가상 경계를 추가했습니다. 새 의미의 ROI 등록 규격은 v3, 기존 v2 읽기는 유지합니다.

5. 빈 보드 글자의 흰 스티커 오인: 등록 이름의 외관 근거를 비교하고 변하지 않은 문자 영역만 제외합니다. 차량이 덮으면 제외하지 않습니다.

6. 사진 자동 등록·수집: 파일 한 번 선택으로 등록→분석→저장, 취소/실패 정지, 연결된 카메라 프레임과 분리했습니다.

7. UI·진단·표시사진에서 세 면 실선/입구 점선을 구분하고 한글 JSON에도 실제/가상 경계를 따로 기록합니다.

8. 합성 시험 중 두 줄 경계 연결과 닫힌 선 오인, 좌표 목록 별칭에 의한 근거 동시 변형을 수정했습니다. 짧은/긴 연결 후보를 함께 검증하고 경계 좌표를 독립 복사합니다.
