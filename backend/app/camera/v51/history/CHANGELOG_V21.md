# V20 → V21



작성일 2026-11-04. V20의 판독/증거 검증 문제와 새 자동 수집 요구를 반영한 실제 코드 수정본입니다. 한 작업 묶음에 V21 하나를 부여했습니다.



## 변경



1. 원형 스티커, 배경 대비 인쇄 흔적, 같은 윤곽 중복 제거, 투시 보정/확대/3개 전처리/회전별 OCR 및 복수 판독 합의.

2. 번호 원문·선택 근거·박스·칸 귀속 검사, epoch 재저장 검사, 촬영시각/프레임 형식 검사, 칸별 OCR 장애 격리.

3. 칸 이름·닫힌 선 경계 자동 등록, 전칸 검사, 구도 anchor 해시/특징 대조 및 매 분석 프레임 재검사.

4. 한 번 시작으로 연결→등록→판독→저장. 자동실패 재탐색, 구도 이동 시 이전 작업 무효화, 저장 오류 시 정지. 고급/수동 조작 접기.

5. 칸명 PNG/한글 JSON, 전체 표시장면, 원본 보존, 품질/미검수 출처, 사람 검수 시 표시자료 갱신.

6. 해시·완성 쌍·범위별 복사 내보내기와 완료 수량/경로 표시, 정보완성·미확인·화질주의 집계.

7. 승인 정답 대비 점유/번호/색 평가와 보류/커버리지/비교 제외 보고서, 카메라 설정 전환 결과 초기화.



## 실제 검증



- 회귀152개 통과(실패/오류/건너뜀0). Tk 원클릭 등록→분석→저장→내보내기, A12/B16 기하, 구도 이동, 저장/복사 오류, 한글 JSON/원본 불변/짝 수, OCR 모의 근거, HTTP 모의 취소 검사 포함.

- `main.py --check` 통과. AST/JSON/구버전 해시/ZIP CRC·파일 해시는 VALIDATION.json과 작업 폴더 PACKAGE_CHECK_V21.json 참조.

- 실제 로컬 CPU OCR: 동일 D39 합성 번호 V20 16/24→V21 20/24(4개 보류), 색24/24. 작은 초록23 수정, 과거 실물49는 파랑색/번호미확인.

- 합성 전칸 이름 자동등록 A12/B16. 자동등록+초록23 인식+칸별28쌍 저장, 내보내기 이미지32·데이터JSON30·원본2 대조. 표시사진 한글/좌표 육안 확인.

- 초기 자동 이름 OCR 누락과 작은 글자 실패를 수정하며 반복 검증했고 중간 실험은 verification_v21에 남겼습니다.
