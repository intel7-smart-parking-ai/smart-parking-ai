# V46 코드 점검과 검증 범위



V46은 V45의 촬영·판독·검수 경로를 바탕으로 위치 근거, 두 프레임의 짝 선택, 빈 기준 등록, 현장 채점과 학습 자료 분할을 보완했다. 두 카메라 통합 수집·검수·저장 복구·학습 자료 내보내기를 구현하고, 모의 시험과 기존 사진 재생으로 검증했다. 신규 실물 환경의 인식률과 장시간 안정성은 추가 검증 예정이다.



| 점검 항목 | 코드에서 보완하거나 확인한 내용 | 시험 결과와 적용 범위 |

|---|---|---|

| ① 직접 판독과 추정 | 같은 원본에서 V45와 V46의 CPU OCR 결과를 비교했다. 현장 대조에서는 실물 칸과 가상 배치 각각에 대해 스티커 번호·색을 점유와 분리해서 채점한다. | 기존 사진의 차량 11칸은 직접 일치 2, 추정 일치 9였다. 서로 다른 번호를 그린 별도 합성 24종은 직접 19, 추정 3, 보류 2였다. 같은 차량의 두 시점을 독립 차량으로 더하지 않도록 정답표에 차량식별표를 추가했다. |

| ② 반사·과노출·방향 | 번호 근거가 사라지거나 66/99의 양방향 근거가 충돌하면 보류하는 판독을 유지했다. | 밝기를 올린 기존 사진은 11칸 중 10칸이 맞고 초록 11번 1칸은 보류였다. 흰색 66/99 두 번호, 네 회전, 두 모드의 16조건에서 모두 흰색을 유지하고 번호를 보류했다. 77의 숫자 부분을 흰색으로 채운 조건도 보류했다. 실제 반사광·자동 노출 조건은 후속 실측 대상이다. |

| ③ 가상 안내선 | 가상 칸을 실물 점유 지표·승인 점유 크롭 수에서 제외했다. 빈 기준 저장, 예측 검증, 실물 이벤트 생성에서도 구분한다. 검수 미리보기는 파란 열린 선, 후보 CSV는 위치 출처와 가상 배치 이름을 쓴다. | 가상 칸을 승인한 모의 장면에서 점유 준비 수·점유 학습 파일 수·점유 비교 분모가 각각 0이었다. 실물과 가상 두 채널을 대조할 때 실물 12칸만 실물 점유 분모에 들어갔다. |

| ④ 두 카메라의 시간 | 연속측정은 양쪽 최근 프레임 중 나이·시작 시각·연결 회차·재사용 제한을 만족하는 조합에서 PC 수신차를 최소화한다. 1회 측정은 미리보기에 표시한 프레임 쌍을 쓴다. | 최신 두 장의 차이가 201ms인 모의 조건에서 양쪽 이전 프레임으로 5ms 쌍을 찾았다. 수신차 동률에서는 최신 쌍을 선택했다. 모의 30fps 입력을 160ms 간격으로 100회 비교했을 때 최신 두 장의 수신차는 5ms 80회·28.333ms 20회였고, 선택된 쌍은 100회 모두 5ms였다. 실제 노출 시각 차이와 움직이는 차량의 위치 오차는 별도 실측이 필요하다. |

| ⑤ 빈 기준과 선 침범 | 약한 스티커 후보는 승인 창에서 해당 칸을 다시 확인하고, 고정 도면의 특징점들이 일관되게 이동하면 해당 프레임의 점유·위치 판독을 보류한다. 경계 정답은 여러 종류를 함께 입력하고 종류별로 채점할 수 있다. | 차량 사진에서 뚜렷한 스티커 4개를 디지털로 가린 후 남은 A-07·A-08을 재확인 없이 등록하려 하자 보류됐다. 실제 빈 사진 A-03에서도 약한 후보가 나왔고, 해당 칸을 확인한 조건에서는 양쪽 빈 기준이 저장됐다. 빈 도면의 수평 이동 0·1px는 12칸 모두 빈칸, 2·4·6·12px는 보류였다. 다른 설치의 허용 이동량이나 차량 가림 검출률은 따로 측정해야 한다. |

| ⑥ 현장 성능과 Geti | 같은 데이터 루트에서 재시작해도 배치 ID를 재사용한다. 같은 과제에서 원본 또는 보정한 크롭 픽셀이 학습·검증·시험 분할에 걸쳐 중복되면 전달을 중단한다. 완료 manifest에 과제·라벨별 분할 수를 기록한다. 연속수집 진단에는 실제 경과 시간, 최대 저장 공백과 채널별 연결 정보가 남는다. | 동일 차량에서 칸 밖 한 픽셀만 바꾼 세 쌍은 사람 승인과 칸별 품질을 통과해도 분할 중복으로 전달이 차단됐다. 두 모의 카메라를 연결한 실제 조작 화면에서 짧은 연속수집 2회를 실행했고, 각각 한 쌍을 저장한 뒤 종료 기록을 확인했다. 모의 선 침범·입구 돌출이 함께 나온 한 칸에 선 침범만 정답으로 주면 선 침범 적중 1과 입구 돌출 오경보 1이 각각 기록됐다. |

| ⑦ 현재 사용 설명 | 빠른 시작·장치 검색·빈 기준·복구·기존 데이터 사용을 현재 버튼과 파일명으로 정리했다. 마커 안내와 과거 구현 기록도 구분했다. | V45 측정 한 쌍과 이전 정답표를 별도 데이터 루트에서 다시 열고 28칸을 내보냈다. 기존 파일 102개의 SHA-256이 모두 같았다. 식별표 없는 기존 정답의 고유 차량 수는 미확인으로 표시됐다. |



**현장 시험 순서**는 새 실물 차량 24대 배치, 조명·방향별 독립 정답 대조, 실제 두 카메라로 30분 연속 수집, Geti 가져오기·학습 전후 비교다. 동일 차체의 다른 각도·촬영분은 픽셀이 달라질 수 있으므로 실제 차량 목록으로 분할을 점검한다. Geti 설치판의 가져오기 결과와 학습 모델 성능은 아직 측정하지 않았다. [현장 시험 절차](START_HERE.md#발표와-현장-검증)
