# V48 일곱 항목과 전체 수집 경로 점검



V44부터 제기된 일곱 항목을 V47 배포 소스에서 다시 확인했다. 한 칸에 복수 스티커가 잡힌 경우의 번호 선택, 중단된 촬영의 완료 처리, 정답 대조에서 학습 자료가 검증됐다고 판단하는 기준을 중심으로 V48을 수정했다. V47에서도 통과하던 단일 스티커와 정상 복구를 대조군으로 함께 실행했다.



## 같은 입력으로 비교한 결과



| 시험 | V47 | V48 |

|---|---:|---:|

| 스티커 두 개를 한 칸에 넣은 합성 6장 중 한 번호로 선택한 배치 | 3/6 | 0/6 |

| 같은 여섯 조합에서 하나씩만 보이게 한 합성 12장의 직접 일치 | 12/12 | 12/12 |

| 중단된 한 쌍에서 저장 예측과 복구 기록이 충돌했는데도 완료로 내보낸 쌍 | 1/1 | 0/1 |

| 같은 중단 시점에서 두 판독이 일치하는 대조군의 정상 복구 | 1쌍·28칸 | 1쌍·28칸 |

| 새 회귀 시험 18개의 기대 결과 충족 | 2/18 | 18/18 |

| 기존 실물 사진에서 차량이 있는 11칸 | 직접 2, 추정 9 | 직접 2, 추정 9 |



스티커 시험은 같은 픽셀을 실물판용·가상선용 두 판독 함수에 각각 입력했다. 두 모드에서 표의 결과가 같았다. 복수 조합은 24+71, 17+32, 22+33, 50+64, 47+35, 30+14다. V47은 첫째·둘째·다섯째 조합에서 각각 24, 17, 47을 선택했다. V48은 여섯 장 모두 번호를 비우고 양쪽 번호를 지지하는 위치 근거를 기록했다. 한 조합에서는 OCR이 추가로 78도 제시했다. 후보 목록은 검수 자료이며 자동 정답 확정에 쓰지 않는다.



## 일곱 항목별 진단



| 항목 | 코드에서 확인하거나 수정한 내용 | 시험 결과와 현장에서 확인할 점 |

|---|---|---|

| ① 번호 추정 | 현재 영상의 직접 판독, 인쇄 모양 및 참고 사진 기반 추정, 보류를 구분한다. 서로 다른 위치에서 번호 근거가 확인되면 먼저 읽은 번호로 단정하던 경로를 수정했다. 저장된 직접 판독의 선택 근거도 점수·상태·합의 방법과 대조한다. | 기존 사진 11칸 중 직접 2·추정 9·오답 0이다. 여섯 참고 차량과 반복 관측이 있어 새 차량 정확도는 독립 정답으로 측정해야 한다. |

| ② 반사·과노출·방향 | 가상선 확대 재판독의 방향 충돌 사유와 후보를 보존한다. 한 스티커에서 방향이 충돌할 때와 서로 다른 위치에서 복수 스티커가 검출될 때를 구분한다. | 기존 사진을 디지털로 밝힌 B 영상의 초록 11은 보류했다. 흰색 66/99의 16가지 시험은 흰색을 유지하고 번호를 보류했다. 숫자 획을 완전히 포화시킨 77도 보류했다. 실제 조명과 노출에서는 다시 촬영해 확인해야 한다. |

| ③ 가상 칸의 의미 | 양 화면이 모두 가상일 때 근거가 없는 프레임은 대기한다. 복수 스티커의 판독 근거가 있는 프레임은 두 원본과 보류 기록을 저장하도록 수정했다. | 대시보드 측정 경로로 두 원본·검수용 칸 자료 생성, 실물칸확인=false, 점유 미확정, 미승인 학습 크롭 0을 확인했다. 실물 점유·전용칸·주차선 평가에는 실물 위치 근거가 필요하다. |

| ④ 두 카메라의 시각·연결 | 연속 수집은 각 카메라의 현재 연결에서 받은 프레임만 사용한다. 재연결로 버퍼가 비면 다음 쌍을 기다린다. 분석·보강·전송 자료 생성 전에 사진과 ROI의 채널·시리얼·해상도 등 촬영 근거를 검사한다. | 끊긴 연결의 마지막 프레임과 다른 카메라의 ROI를 사용한 입력을 차단했다. 기본 100ms는 PC 수신 시각 차이다. 움직이는 차량의 위치 오차와 센서 노출 동기는 별도 계측이 필요하다. |

| ⑤ 실물 점유·빈 기준 | 빈 기준과 현재 영상의 위치·연결 일치, 약한 스티커 후보에 대한 사람의 재확인을 점검했다. | 저장된 빈 보드 A에서 A-03 재확인 후보가 나왔고 B에는 없었다. A 영상의 수평 이동 0·1픽셀은 빈칸 12, 경계 경고 0이었다. 2·4·6·12픽셀 이동과 재연결에서는 보류했다. 이 값은 해당 사진의 실험 결과다. 등록 시 가려진 차량·손·새 물체는 두 원본을 사람이 확인해야 한다. |

| ⑥ 현장 성능·Geti | 학습 번호 크롭의 배치·분할·파일 경로, 승인 당시 파일 해시와 좌표, 원본 픽셀, 독립 정답을 대조한다. 중복 목록·칸을 거부한다. 파일 존재 수와 전체 검증 통과 칸을 분리했다. | 내보낸 뒤 예전 승인을 다시 편집해도 해당 시점의 근거를 대조했다. 실제 두 카메라 장시간 운전, 신규 실물 배치, 물리적 경계 침범, Geti 설치판의 가져오기와 학습 효과는 현장 시험이 남았다. |

| ⑦ 사용 지침 | 실행 창·설명서·검증 기록의 제품 버전을 V48로 맞췄다. 복수 스티커 보류, 재연결 후 대기, 복구 충돌, 학습 대조 수치 해석을 사용 설명서에 추가했다. | 시작 안내와 검증 이력을 구분했다. 이전 장치 시리얼은 설치 당시 기록으로 표시했다. 기존 데이터 루트는 ‘저장 폴더 선택’으로 이어 쓴다. |



## 프로그램 경로별 점검



- **실행과 장치 입력.** 설정과 두 카메라 배정에서 미리보기·프레임 선택·작업자 호출까지 확인했다. 이전 시험 하나에서 채널 B의 프레임을 공급하면서 해당 채널을 정지 상태로 두고 있었다. V48 시험에서는 B도 실행 중인 연결과 이력을 만들도록 수정하고 기존 판정 조건을 유지했다.

- **위치·판독·저장 계약.** 자동 보드 검출, 수동 ROI, 빈 기준, 가상 안내선에서 데이터가 갈라지는 지점과 번호 근거가 저장되는 지점을 확인했다. 100개 Python 파일의 구문을 검사했다. 테스트 폴더를 제외한 53개 파일에는 함수·메서드 550개와 클래스 34개가 있다. 파일 수와 자동 시험 수는 실행된 코드의 줄 단위 커버리지와 구분한다.

- **원본·복구·내보내기.** 두 원본과 복구 기록을 기록한 직후 시험용 자식 프로세스를 종료했다. 정상 대조군은 한 쌍·28칸이 복구됐다. 별도 복사본에서는 저장 예측 하나를 내용은 다르지만 형식은 유효한 예측으로 바꿨다. V48은 충돌한 측정 한 쌍을 보류하고 내보내기 0쌍, 원본 해시 동일, 복구 기록 보존을 확인했다. 시험 복사본의 원래 예측을 복원한 뒤 연속 두 번 복구해도 한 쌍·28칸이었다. 자동 복구와 수동 재생성 모두 같은 비교를 거친다.

- **검수·학습·현장 대조.** 기존 승인 파일의 UTF-8 BOM·공백처럼 내용상 같은 표현도 SHA-256에는 영향을 준다. 검수 이력에 기존 바이트를 그대로 보관해 예전 전달본이 가리키는 승인을 추적한다. 과거 버전에서 이미 소실된 승인 파일은 당시 백업이 필요하다. 학습 분할은 기존 배치 ID 해시 규칙을 내보내기와 검사에서 공통으로 사용한다.

- **이전 자료와 실행 경로.** V47로 만든 원본·기록 102개는 V48에서 재개·조회·내보낸 뒤에도 바이트 해시가 일치했다. 기존 정답표로 실물 28칸을 대조했고 내보낸 측정은 두 원본·28칸·사진 32개·JSON 30개였다. 배포 ZIP의 실제 Windows 실행기로 설정·배치·장치 설정을 검사했다. 데이터 계약과 설치 구도를 유지했다.



## 수치의 해석과 다음 시험



전체 자동 회귀 645개를 실행했다. 기존 627개와 새 시험 18개가 모두 통과했고 실패·오류·건너뜀은 각각 0이었다. 새 시험에서 V47이 충족하지 못한 16개는 같은 원인의 여러 진입점과 새 보고 필드를 포함한다. 이를 서로 다른 버그 수 또는 전체 프로그램의 오류율로 환산할 수 없다.



기존 합성 24개는 직접 일치 15·추정 일치 3·보류 6이었다. 앞서 사용한 추가 합성 세 세트 72개는 직접 일치 42·추정 일치 9·보류 21, 별도 합성 24개는 직접 일치 19·추정 일치 3·보류 2였다. 이 세 묶음 모두 오답 0이며 V47 재생과 칸별 결과가 같았다. 이번 개선은 복수 스티커의 단일 번호 선택과 검증되지 않은 자료의 완료 처리를 줄인 것이다.



이번 작업 중 RealSense SDK가 열거한 실장치는 0대였다. 다음 시험은 ① 새 실물 차량 24대와 식별표 → ② 조명·방향·실제 선 침범을 독립 정답과 대조 → ③ 두 카메라로 실제 30분 연속 수집 및 저장 공백 확인 → ④ 대상 Geti 설치판에서 가져온 수와 분할 확인, 독립 시험 세트로 학습 전후 비교 순서다.
