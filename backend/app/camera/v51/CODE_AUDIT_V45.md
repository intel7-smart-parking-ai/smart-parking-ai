# V45 반사·과노출 및 방향 혼동 점검



V44의 두 카메라 수집 흐름에서 번호를 판독하는 순서, 원본과 조명 보정 영상의 관계, 보류 원인이 검수자에게 전달되는 과정을 점검했다. V45는 보류 원인과 판독 근거를 남기고 66/99의 충돌 처리를 보강한다.



| 점검 영역 | 확인한 동작과 근거 |

|---|---|

| 카메라·등록 | 두 시리얼, 연결 회차, PC 수신 시각과 빈 기준을 대조한다. 가상 칸과 실물 칸의 출처 구분은 기존 회귀검사로 확인했다. |

| 원본·조명 | 칸별 원본과 분석 영상에서 같은 다각형의 포화 비율과 명암을 측정한다. 흰 종이에 숫자가 남은 예와 영역 전체가 포화된 예를 분리해 시험했다. |

| 번호·색 | 일부 방향에서 숫자가 조각으로 나오면 다른 방향을 계속 읽는다. 66/99는 반대 방향의 후보까지 검사한다. 인쇄체 추정의 1·2순위가 66과 99이면 실물과 가상 모드에서 번호를 보류한다. 추정 후보에 연결된 OCR 원문·좌표도 예측 기록에 보존한다. |

| 저장·복구 | 기존 원본, 측정 ID, 크롭, 표시 PNG, 검수 정답을 연결하는 흐름을 회귀검사했다. 새 진단은 칸별 한글 JSON에 기록하며 저장된 예측과 대조한다. JSON 진단을 변경하고 파일 해시까지 바꾼 시험에서도 잘못된 묶음을 거부했다. |

| 승인·전달 | 미승인 재생 자료의 학습 크롭은 0장이었다. 이전 진단 없는 예측의 저장·읽기와 검수·내보내기·중단 복구 관련 누적 시험도 통과했다. |



## 실제 실행 결과



누적 회귀 594건이 모두 통과했다. 기존 580건에 V45 시험 14건을 추가했다. 물리 카메라와 실서버는 연결하지 않았다.



| 같은 이미지로 비교한 시험 | V44 | V45 |

|---|---|---|

| 기존 Intel 사진의 점유 11칸 | 직접 2, 추정 9 | 직접 2, 추정 9 |

| 같은 사진을 어둡게 변환 | 11/11 일치 | 11/11 일치 |

| 같은 사진을 밝게 변환 | 10/11 일치, 1건 보류 | 10/11 일치, 1건 보류 |

| 별도 합성 번호 24종 | 직접 19, 추정 3, 보류 2 | 직접 19, 추정 3, 보류 2 |

| 흰색 66/99 × 네 회전 × 두 모드 | 번호 제시 6, 보류 10 | 흰색 유지, 번호 보류 16 |

| B/B-08의 77 숫자 영역을 흰색으로 채운 재생 | 번호 보류 | 번호 보류 |



기존 사진과 일반 합성 24종 비교에서 두 버전 모두 오답과 빈칸 오번호가 0건이었다. 방향 시험의 V44 제시 6건은 인쇄값과 일치했다. V45에서는 해당 6건도 검수 대상으로 넘긴다. 상하 방향이 불명확한 번호에 대해 자동 판독 범위를 줄이는 선택이다. 합성 16건은 스티커 두 종류를 반복한 시험이다.



밝은 B 카메라 A-07의 초록 11번은 여전히 보류된다. 별도 밝기 탐색에서 녹색 원 후보의 반지름은 약 7.8픽셀이었고, 원본과 보정본의 국소 OCR 모두 번호를 반환하지 못했다. 인쇄체 유사도 문턱 이전에 후보가 제외될 수 있으며 이후 참고 사진과의 일치도도 제한적이다. 원본 영역에 남은 획을 확대해 확인하고 필요하면 재촬영해야 한다. 숫자 근거와 실물 방향 표시 없이 11이나 99를 복원했다고 볼 근거는 없다.



앞선 미배포 실험은 모든 번호의 방향 충돌을 폭넓게 보류해 별도 합성 24종 일치가 9건으로 감소했다. 최종 V45는 일반 번호의 기존 판독 방식을 유지하며 같은 입력에서 22건이 일치했다. 촬영 데이터 schema·contract_revision·설치 pose는 기존 값을 사용한다. 새 필드의 의미와 기존 데이터 경로 선택 방법은 [사용 설명서](START_HERE.md)에 있다.
