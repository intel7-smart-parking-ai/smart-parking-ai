# V51 종합 진단



## 측정 실패의 원인과 수정



저장된 두 보류 측정의 A/B 원본과 각 빈 기준을 대조했다. 주차판의 영상 위치가 달라지면서 고정 특징점 검사가 실패해 두 장면의 측정·저장이 중단됐다. V50에서는 확보한 두 쌍과 첨부 화면의 여섯 채널 재생이 모두 보류됐다.



V51은 등록된 인쇄 도면을 현재 영상에서 다시 찾아 빈 기준을 좌표 변환한다. 같은 장치·주차장·시점·해상도·연결 구간, 동일 칸 목록, 각 줄의 주차선 일치, 이동량·면적 비율·재투영 오차를 확인한다. 이동량은 영상 긴 변의 20% 이내, 칸 면적 비율은 0.5~2배, 코너 잔차는 2픽셀 이내이고 각 줄에서 최소 2/3의 칸 주차선 근거가 필요하다. 이 값은 이번 회귀 조건이며 현장 허용 오차의 실측 성적은 추가 검증 대상이다.



변환 후 생기는 인쇄선의 작은 픽셀 차이를 허용하고 도면 밖 배경 변화의 영향을 줄였다. 칸의 밝기 변화에 새로운 윤곽이 부족하면 점유와 번호를 보류한다. 원본·빈 기준·변환 행렬·지원 주차선을 저장해 재열람과 내보내기에서 다시 대조한다. 정상 저장 6장 재검사와 변환 근거 누락·변경 18건 차단을 확인했다.



## 조작과 큰 라벨



기본 화면에 F5 자동 수집, Space 한 번 저장, Esc 정지를 배치하고 세부 버튼을 설정·검수에 접었다. 초기 복구 중 수집 요청 대기, 중복 요청, 연결 중 취소, 입력란·대화상자에서의 Space 처리도 시험한다.



사각형 후보는 외곽 직선, 칸 내부 귀속, 테두리 색, 내부 검정 획으로 찾는다. 작은 칸 인쇄 글씨와 균일한 색 영역을 제외한다. 숫자는 사각형 안쪽 원본을 정면으로 편 뒤 네 방향과 세 영상 표현으로 읽는다. 전체 영역 재판독은 점수 0.90 이상을 사용하고, 같은 방향의 두 영상 이상이 합의해야 확정 후보로 저장한다. 다른 번호·방향 근거가 충돌하면 번호를 보류한다. 기존 국소 검출 경로의 합의 조건도 확인한다. 이 점수는 정답 확률로 해석하지 않는다.



사용자 제공 Intel 사진에서 11·49·23·34·77을 직접 판독했고, 흰색 87은 반대 방향의 28과 충돌해 번호를 보류했다. 여섯 칸의 색은 모두 사진의 육안 정답과 일치했다. 이 정답은 제공 사진을 보고 작성했으며, 현장에서 독립적으로 작성한 배치표는 아직 없다. 새 번호 23을 별도 정답 목록으로 강제하지 않았다. 휴대폰 참고 사진의 번호를 학습 템플릿으로 추가하는 작업은 실시하지 않았다.

## 데이터와 검증 범위



V50 배포 소스와 ZIP을 보존하고 V51 폴더에서 수정했다. 데이터 규격·설치 pose를 제품 버전 때문에 변경하지 않았다. 재정합이 적용된 기록에는 변환 근거가 추가된다. V51은 기존 V50 자료의 원본·기록 102개 해시를 보존하면서 28칸 내보내기와 현장 정답표 대조를 수행했다. V51의 새 변환 근거가 들어간 자료는 V51에서 검수한다.



전체 시험 수와 성공 여부는 TEST_RESULTS_V51.json, 사진별 결과와 UI 시험은 FIELD_REPLAY_V51.json에 기록한다. 회귀시험의 의도적 손상·보류 상황은 로그에 예외 문구를 출력할 수 있으며 최종 실패·오류 개수로 결과를 확인한다.



실제 차량의 윤곽과 선 침범, 조명 변화, 움직이는 차량, 장시간 수집, 새 카메라 위치, 새 라벨의 다양한 거리·폰트·각도에 대한 독립 성적이 필요하다. 현재 자료에서 확인한 오류의 수정과 현장 전체의 오류율을 구분해 발표해야 한다.
