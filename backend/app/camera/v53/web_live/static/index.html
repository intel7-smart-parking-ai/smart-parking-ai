팀 예제는 기능 점검용입니다. 학습 사진과의 중복 여부가 확인되지 않아 독립 정확도로 계산하지 않습니다. 이 결과는 서버로 보내지 않습니다.

판독 기준과 사용 방법

F5로 시작하면 양쪽 카메라의 판독 데이터를 이 PC의 runtime/collection.db에 자동 기록합니다. 탭을 닫아도 서버가 켜져 있으면 계속 수집합니다. Esc 또는 정지 버튼으로 두 카메라의 수집을 종료하세요. Space로 현재 결과 JSON을 내려받을 수 있습니다. 원본 영상의 연속 녹화는 제공하지 않습니다.

서버에 보내려면 각 판독 화면의 칸 이름과 실제 도면을 대조해 ‘칸 위치 맞음’을 누르세요. 빈칸 관측에는 차량·손·물체가 없는 상태에서 등록한 빈 기준이 필요합니다. 흰색은 일반, 초록은 전기차, 파랑은 장애인 차량입니다. 번호 후보와 보류는 표에 구분해 표시합니다.
