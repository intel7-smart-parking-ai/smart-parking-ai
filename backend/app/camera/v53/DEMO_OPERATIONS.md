# V53 카메라 시연 운영표 (11/11 실측)

교육장 카메라 PC에서 시연 서버로 실제 전송하며 측정했다. 코드 기준은 main(#105·#106·#112·#114·#115·#118 포함)이다. 리허설 체크리스트와 발표 Q&A("실시간 오류에 어떻게 대응하나요?")에 그대로 쓴다.

## 1. 시연 전 체크리스트
1. 카메라·조명·판 위치를 고정한다. 이후로는 만지지 않는다.
2. `start_demo_send.ps1 -BaseUrl <시연 서버>`로 실행하고 토큰을 직접 입력한다. 테스트 서버와 시연 서버로 동시에 보내지 않는다.
3. `assets.local.json`에 `"mock_fire_cars": ["11","23","42"]`, 실행 창에 `V53_UNATTENDED_SEND=1`(실행기 기본값)인지 확인한다.
4. 두 화면 모두 '칸 위치 맞음' → '전송 켜기'.
5. 빈 주차장에서 '빈칸 기준 등록'을 한 번 한다.
6. LED 차는 **LED를 끈 채** 놓고, 번호가 읽힌 뒤 LED를 켠다.
7. 카메라 화면은 크롬 별도 창으로 띄우고 최소화하거나 닫지 않는다.

## 2. LED 차(11·23·42)를 둘 수 있는 칸
D-75 해제(#112·#114) 뒤 피할 칸은 없다.

| 주차장 | 11/11 실측 |
| --- | --- |
| 개발원(A) | A-02(42번 40/40), B-02(42번 65/65) |
| 부산역(B) | A-04(42번 174/174), A-05(11번 174/174·64/64), A-06(23번 174/174·64/64) |

**LED 차 세 대를 나란히 둬도 된다(부산역 A-04·A-05·A-06, 개발원 B-01·B-02·B-03).** 개발원 B-01(23)·B-02(11)·B-03(42)도 번호·LED 58/58로 100%였다. 11/11 실측: 11번을 돌린 방향 87/87, 세 대 모두 반대로 돌린 방향 73/73으로 세 칸 모두 번호·LED 100%였다. **예외는 11번을 LED가 스티커 바로 위에 오는 방향으로 둘 때**뿐이다(번호 59/85, LED는 85/85). 이 방향이면 차를 180도 돌려 놓는다.

흰 차(42·11)의 LED는 두 화면이 승인돼 있어야 판정된다. 앱 재시작 직후 LED를 켜 둔 채면 스티커가 가려져 번호를 못 읽고, 그러면 LED도 판정되지 않는다(LED를 껐다 켜면 해결).

| 배치 | 번호 | LED | 서버 |
