## 변경 제한

backend/app/chatbot/ 내부만 수정한다. API 경로·응답 형식·칩 ID·설정 키·기존 CSV/테스트 기대값·lots.json 값은 보존한다. 이번 목록 외 기능은 먼저 보고해 허락을 받는다. 새 스레드·의존성·전환 스위치를 추가하지 않는다. DATA-01 재시도는 오늘 목록 밖이므로 이번에 끼워 넣지 않는다.

전체 검증은 수정이 모인 뒤 설치/미설치·RUN_SLOW·질문 248·기본 응답 242 스냅샷·브라우저·리허설 6/6·api_smoke를 한 묶음으로 수행한다. 관련 검사 실패는 구현 실수/검사 오류/설계 회귀로 구분해 먼저 원인을 확인한다. 승인된 새 차단 상황만 변화를 허용하며 기존 스냅샷은 유지한다. 실제 LLM API 호출은 하지 않는다.
