# 챗봇 평가 장부

버전(커밋)마다 **같은 질문 모음**을 돌린 기록과, **문제 → 원인 → 수정 → 확인**의 추적표. 이 폴더가 Langfuse를 대신하는 로컬 기록이다.

## 쓰는 법

```powershell
cd backend/app/chatbot/parking-chatbot
# 1) 실행 (모델 켠 상태, 키는 .env 경로로만). --save 로 runs/ 에 보관
python tools/run_dialogs.py tests/dialogs/tricky_demo.json --env-file <키 .env> --label <이름> --save
# 2) 두 실행 비교 → 질문별 좋아짐/나빠짐
python tools/compare_runs.py docs/eval/runs/<전>.json docs/eval/runs/<후>.json --out docs/eval/compare_<이름>.md
# 3) 다시 볼 턴·사용자 👎 모으기(로컬 기록 또는 Langfuse)
python tools/langfuse_review.py --local .monitoring/turns.jsonl
```

- 실행 기록(`runs/*.json`)에는 메타(커밋·모델·시간 제한·날짜)와 턴마다 **답·경로(route)·단계별 이유·AI 호출 수·토큰·시간·자동 판정(grade)** 이 남는다.
- 자동 판정 등급(`tools/eval_common.py`): AI 답 > AI 조회·코드 문장 = 코드 담당 > 조회 없이 되묻기 > 규칙 답으로 떨어짐(시간 초과·검사 탈락·AI 불가·확정 안내 미준수) > 이해 못 함.
  같은 등급에서 문장만 달라진 것은 사람이 본다(모델 답은 매번 조금씩 다르다).
- 모델 호출 비용(실측): gemma 턴당 약 $0.0005, Claude Haiku 5.5 약 $0.0013. 질문 모음 한 번 ≈ Haiku $0.06.
