## 팀 연결과 남은 일

- 팀 main 실배치는 수행하지 않았다. 확인한 공개 main에는 챗봇 라우터 등록이 없으며, 프런트 `ChatPanel.jsx`는 `messages`를 읽는다. 챗봇 ZIP의 고정 응답은 최상위 `text`다. 팀 서버 등록과 화면 연결을 담당자 변경으로 검증해야 한다.
- 공개 main의 billing은 데모 연결을 넘긴 앱에서만 활성화된다. 공개 조회 목업의 차량에는 세션 ID가 없고 `/alerts`도 제공하지 않는다. 실제 조회·billing 통합, 인증 설정, Windows 실기기·실제 LLM 계정은 이번 복제 검증 범위에 포함되지 않았다.
- 팀 요청 문장은 문서에 남겼다. 배포 후 `entry_at`이 없거나 후보 일부에만 있으면 기존 안내를 유지한다.
- 다음에 할 것. 팀 실행 환경에서 등록·프런트 응답·조회와 billing 단일 주소를 맞춘 뒤 연결 시험한다.

사람이 PR을 올릴 때는 `feature/KAN-9-chatbot-integration-hardening`에서 `git add backend/app/chatbot`으로 범위를 제한한다. 병합 담당은 김한별님이다.
