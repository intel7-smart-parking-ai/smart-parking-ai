## 유지한 항목

잠금, 요청 재전송, 캐시 세대, 알림 커서, 결제 직렬화, Lv2 정책은 동시 요청과 결제 안전성에 직접 관련돼 구조를 그대로 유지했다. 불확실한 죽은 코드와 내부 매직 넘버도 호출처·운영 의미 확인 없이 삭제하거나 설정으로 옮기지 않았다. 성능 향상을 주장하지 않는다.
