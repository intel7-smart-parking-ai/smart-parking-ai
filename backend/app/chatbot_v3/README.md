# Chatbot v3 재구성 프로토타입

2026-11-06 복구 기록을 바탕으로 재작성했습니다. 유실된 파일과 바이트 단위로 같은 복원본은 아닙니다.
기존 규칙 파서와 engine.py를 사용하지 않으며, 기존 `/chat` 및 화면에 아직 연결되지 않았습니다.

Coordinator(LLM) → 고정된 조회 도구/설정집 → 검증된 사실 생성 → Reporter(LLM은 사실 ID 정렬만).
일반적인 요청은 모델을 최대 두 번 호출합니다. 요금은 서버 계산 결과만 표시합니다.
요금 GET은 견적을 저장하므로 요청 ID별 결과/실패를 메모리에 보관하며 자동 재시도하지 않습니다.
프로세스 재시작 뒤의 중복 방지는 보장하지 않습니다. 세션과 요청 저장소 모두 단일 프로세스 메모리입니다.

```bash
python -m backend.app.chatbot_v3 --env-file /안전한/경로/.env --backend-url http://127.0.0.1:8000
```

필수 설정은 `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`입니다. 모델은 사용자가 선택해야 하며 기본값을 임의로 정하지 않습니다.
`LLM_MODEL`은 이전 설정의 대체 이름이며 두 설정이 충돌하면 중단합니다. 키·응답 원문은 오류에 노출하지 않습니다.
설정파일은 명시한 파일만 읽고 실제 환경 변수가 우선합니다. API 키나 `.env`는 Git에 넣지 마세요.

인증된 백엔드, HTTP 신규 채팅 라우트, 화면 연결, Langfuse, 영구 세션 저장, 전체 턴 시간제한은 미구현입니다.
모델이 해석한 장소가 실제 사용자 의도와 맞는지는 실제 한국어 평가가 추가로 필요합니다.
현재 테스트는 모의 모델이며 OpenRouter 결제를 발생시키지 않습니다.

## 키 없이 화면 연결 시험

별도 `preview:create_preview_app`과 `frontend/chat-v3.html`을 추가했습니다.
실행·시간제한·세션 수명·지원 범위는 [시험 실행 문서](../../../docs/chatbot-v3/KEYLESS_PREVIEW.md)를 참고하세요.
위 콘솔 구현의 제한과 별도 gateway의 보완 사항을 구분합니다. 기존 운영 `/chat`은 교체하지 않았습니다.
